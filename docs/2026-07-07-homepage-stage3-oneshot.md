## §0. 통합 결정 필요 사항 (먼저 — 두 정본 사이 불일치 발견)

### 0-1. 제품 명칭 통일 ★즉시 결정 필요
두 정본이 서로를 다르게 부른다:
- 업로드 정본 §2-12 크로스셀: "**누구나 대시보드** 보기"
- 대시보드 정본 S9: "**NGN 업로드**로 콘텐츠를…"

**추천: "누구나 컨텐츠"(노출) + "NGN 대시보드"(광고)로 통일.**
근거: ①각 정본이 자기 자신을 부르는 이름이 이것 ②타깃 격 구분과 일치 — "누구나"=가게 사장님 톤(친근·진입장벽 제거), "NGN"=규모 있는 셀러·브랜드 톤(비즈니스·격식) ③크로스셀 문구 2곳만 고치면 됨(각 정본의 상대 호칭만 수정).

### 0-2. "소상공인" 단어 잔존 지점 (화면 노출분만 교체)
- 업로드 정본 §6 H2: "**소상공인**이 네이버 노출을 직접 관리하는 법" / 키워드 `소상공인 네이버 노출`.
- **판정**: meta keywords·검색 타깃 문자열은 검색어라 유지 가능하나, **화면에 보이는 H2·본문에는 쓰지 않는다** → H2는 "가게 사장님이 네이버 노출을 직접 관리하는 법"으로. (북극성 문장의 "소상공인"은 내부 문서 표현 — 화면 카피 아님, 문제없음.)

### 0-3. 가격 헤드라인 수치 검증 실패 (업로드 §2-8)
"대행사 한 달 값이면, 1년을 씁니다" — **검산 불성립**: 대행 앵커 월 30만(하단)~90만(상단) vs 베이직 연 118.8만(9.9만×12). 상단 앵커 90만으로도 1년이 안 나옴(약 9개월). 과장 금지 원칙 위반 소지.
**추천 대체**: 정본 §7의 한 줄 "**대행사 월 30만 대신, 월 9만 원부터. 첫 달 무료, 약정 없음.**"을 가격 섹션 헤드라인으로 승격(신규 창작 아님·수치 정직). 기존 안 유지 여부는 CEO 판단.

## §A. 홈(/) · 시작(/start) · 글로벌 요소 · 크로스셀 동선 [신규 기획]

### A-1. 홈(/) — "얕은 안내소" (IA 확정대로: 정체성 1줄 + 두 갈래 + 크로스셀)

**목적**: 30초 안에 방문자를 자기 갈래로 보낸다. 홈에서 설득하지 않는다 — 설득은 랜딩 관할. **홈에서 기능 나열 금지**(랜딩과 중복 = 파편화).

| H1 | 히어로 = 정체성 1줄 + 분기 | 정체성: "대행 없이 직접" 한 줄(예시 방향: "대행사 없이, 노출도 광고도 직접."). 바로 아래 **두 갈래 분기 카드 2장**: ①누구나 컨텐츠 — "검색에 우리 가게가 보이게" → /content ②NGN 대시보드 — "광고·매출을 한 화면에서 직접" → /ads | `HeroMinimal`(텍스트 중심·라이트 — 안내소는 가볍게) + `bento-grid` 2열 변형. 대안: `HeroAurora`(과함 — 다크 히어로는 /ads에 양보 권장) |

### A-3. 글로벌 요소

- **Nav** (`Nav` 재사용 — 로고+3링크 구조 그대로): 로고(→/) · **누구나 컨텐츠**(/content) · **NGN 대시보드**(/ads) · [시작하기] 버튼(→/start, primary). 스크롤 배경변화 유지.
- **Footer** (`Footer` 재사용): 3열 — 회사정보 / 두 제품 링크 / 시작·문의. 통합 브랜드(업로드 정본 섹션 13 "푸터=통합 브랜드"와 일치).
- **PromoBanner** (`PromoBanner` 재사용): "모든 요금제 첫 달 무료 · 카드 등록 없음" 1줄 — 전 페이지 상단. 랜딩 가격 섹션과 문구 중복되므로 배너는 이 1줄만(중복 강박 금지).

### A-4. 크로스셀 동선 (전체 지도)

```
/content 12섹션 마감 CTA ──"광고까지 필요하세요?"──→ /ads
/content 가격표 하단 훅 ──"광고 세팅은 무료로 도와드립니다"──→ /ads
/ads S9 한 줄 ──"노출이 먼저라면"──→ /content
/ (홈 H2·H3) ── 분기 자체가 동선. 겸용 1줄만 ──→ 각 랜딩
/start 폼 "둘 다" ── 크로스셀 최종 수확
```
원칙: **랜딩당 크로스셀 1~2곳 한정**(정본 명시 위치만). 명칭은 §0-1 통일안 적용.

## §E. ★ 요금 — 축 검증 + 재구성안 (CEO 최우선 검증 포인트)

> **축(확정 지시)**: "위로 갈수록 사람이 챙긴다" — 자동(발행·노출·글감·광고)=전 티어 기본 / 스탠다드+ **카카오톡 다이렉트 소통** / 프리미엄 **영상 직접 제작(자동 아님)·제안서·전담**.

### E-1. 업로드 — 현 v2 가격표는 축과 충돌 (재구성 필요)

**충돌 진단**:
1. v2 표는 **자동 기능(다채널 발행·순위 추적·월간 리포트)을 스탠다드 게이트**로 쓴다 → "자동=전 티어 기본" 축 위반.
2. v2 스탠다드에 **카카오톡 다이렉트 소통이 없다** → 축의 스탠다드 차별 요소 미반영.
3. 프리미엄(영상·제안서·전담)은 축과 일치 — 유지.

**재구성안 (추천)** — 축 그대로 + 용량 축 병행(두 축은 상충하지 않음: "자동이라는 성질"은 전 티어 동일, "폭"만 차등):

```
베이직 99,000 — 자동은 전부 됩니다
  다채널 자동 발행 · 노출 최적화 · 1년치 글감 · 순위 추적 · 월간 노출 리포트 · 리뷰 답글
  (용량 상한 CEO 확정 필요: 예 — 매장 1곳 / 핵심 채널 네이버 블로그+플레이스)
스탠다드 199,000 ⭐가장 인기 — 사람이 옆에 붙습니다
  베이직 전부 + 카카오톡 다이렉트 소통(담당자와 바로) + 전 채널(인스타·페북·구글·유튜브 쇼츠) + 매장 확장
프리미엄 390,000~490,000 — 만들어서 드립니다
  스탠다드 전부 + 쇼츠·릴스 직접 제작(자동 아님 — 월 N편 기준 명시 필수) + 콘텐츠 제안서 + 전담 관리
```

**구간 합리성 판정**:
- **9.9→19.9(+10만)**: 카톡 소통 **단독으로는 취약**("10만 더 받는데 1개 추가" 패턴). → 위처럼 **채널 폭(핵심 채널→전 채널)을 병행**해야 방어됨. 채널 폭은 자동 기능의 유무가 아니라 용량이므로 축 위반 아님. 베이직 상한(매장 1·핵심 채널)을 표에 **명시**해야 저가가 방어된다(대시보드 정본도 같은 원리 지적). — 사람 개입 항목(예: 월 1회 방향 점검)을 더 얹을지는 운영 원가가 걸린 **CEO 결정 사항**(기능 지어내기 금지라 제안만).
- **19.9→39~49(+19~29만)**: **정당** — 영상 직접 제작=사람 노동. 검산: 스탠다드 19.9 + 쇼츠 옵션 월 4편 12만 = 31.9만 < 프리미엄 39만 → 차액 7만+ = 제안서+전담 관리 값으로 셈이 성립. 단 **39~49 범위의 기준(편수? 매장 수?)이 정본에 없음** → "39만=월 2편 / 49만=월 4편" 식 기준 명시 필수(없으면 고객이 옵션과 비교 계산 불가).
- 쇼츠 옵션(편당 3~5만·월 4편 12만)은 유지 — 스탠다드 이용자의 중간 사다리 역할.

### E-2. 대시보드 — 갭 4배 문제 + 축 적용 재구성

**진단**:
1. v2는 "월간 리포트 자동"을 프로 게이트로 쓴다 → 리포트는 자동 → **"자동=전 티어 기본" 축과 충돌.**
2. **스타터 9.9 → 프로 39~49 = 4배 갭, 중간 없음** → "한 단계 올리기"가 심리적으로 불가능한 구간.
3. 사람 요소는 비즈니스(전담)에만 있음 — 대시보드 타깃(자체 직원 있는 규모 셀러·브랜드)은 셀프서브가 본질이라 사람 축이 업로드보다 얇은 것 자체는 자연스러움. 차등의 주축은 **용량**(스토어 수·연결 매체·보존 기간)이 맞다.

**재구성안 (추천)** — 업로드와 가격 사다리 대칭(9.9 / 19.9 / 39~49 / 문의)으로 브랜드 전체 일관성 확보:

```
무료체험 — 1개월 전 기능 (+ 가입 전 데모 체험, §D-2)
스타터 99,000 — 1인 쇼핑몰: 스토어 1 · 연결 매체 2(예: 메타+카페24) · 월간 AI 리포트 포함(자동=기본)
그로스 199,000 [신설 제안] — 성장 셀러: 스토어 1 · 전 매체(메타·구글·카페24·GA4) · 데이터 보존 연장
프로 390,000~490,000 — 브랜드: 다(多)스토어 · 우선 지원 · (사람 요소: 분기 리뷰 등 CEO 결정)
비즈니스 문의 — 전담 지원·연간 맞춤 (사람 축 최상단)
```
- 대안(티어 수 유지 원할 시): 프로 하한을 29만으로 내려 갭 3배 이내로 — 단 업로드와 사다리 비대칭 남음. **추천은 그로스 신설안.**
- 스타터의 "매체 2" 상한은 표에 반드시 명시(정본 자체 지적사항).
- 금액은 정본 명시대로 **제안값**(아드리엘 라이트 9만·팀 39만~ 방어선) — 최종 확정=타깃 광고비 분포 확보 후(CEO).

### E-3. 공통 표기 (두 가격표 하단 고정)
"모든 요금제 1개월 무료 · 카드 등록 필요 없음 · 약정 없음 · 광고비 % 수수료 없음(대시보드)" — PromoBanner(§A-3)와 문구 계열 통일.
