## 1. 필수 페이지 4종 (심사관이 실제로 열어보는 것)

| 페이지 | 내용 요건 | 어느 심사가 보나 |
|---|---|---|
| **서비스 소개** | "누구나 콘텐츠"가 뭘 하는 서비스인지 **실제 기능 기준**으로 설명한다. 현재 유료 상품은 네이버 블로그 운영이 중심이다. 메타·구글 기능은 심사와 계정 상태에 따라 이용 가능 범위가 달라짐을 구분한다. 과장·미구현 기능 서술 금지 | 구글(반려 사유 직격), 메타 |
| **개인정보처리방침** (공개 URL, 로그인 없이 접근) | 수집 항목, 이용 목적, 보관 기간, 파기 절차, 처리업체, 정보보호 책임자·연락처와 **앱 안 문의 또는 이메일을 통한 계정 삭제 절차**를 구체적으로 설명 | **메타(필수 입력란)**, 구글, 네이버, 카카오 |
| **이용약관** | 표준 수준이면 됨(서비스 범위·책임·해지) | 메타 권장, 네이버·카카오 |

## 2. 도메인 통일 (반려 단골 사유)

실제 도메인 구조 (확인됨):
- **`nugoona.co.kr`** = 회사 홈페이지 (제작 중, 방침·약관·소개가 여기 올라감) — 구글 GBP 신청에 기재된 도메인.
- **`upload.nugoona.co.kr`** = 서비스 앱(누구나 콘텐츠) — 메타·구글 OAuth 리다이렉트가 이미 여기로 등록됨 (`META_REDIRECT_URI`·`GOOGLE_BUSINESS_REDIRECT_URI`·`APP_URL` 전부 upload.nugoona.co.kr).
- `board.nugoona.co.kr` = **대시보드(별개 프로젝트)** — 서비스 홈페이지 아님. ⚠️ 현재 **메타 앱 콘솔의 사이트 링크가 이 대시보드 주소로 잘못 등록돼 있음** → 심사 전 `nugoona.co.kr`(또는 upload)로 교체 필요 (Upload 쪽 액션).

원칙: 심사 서류·앱 콘솔의 도메인/방침 URL = **`nugoona.co.kr` 정본으로 통일**, 앱은 upload 서브도메인으로 홈페이지에서 링크. 방침 URL은 **바뀌지 않을 최종 URL**로(심사 후 이동 금지).

## 3. 심사별 추가 요건 (홈페이지 밖 — 참고용, 실행은 Upload 쪽)

- **구글 GBP API 재심사**: 홈페이지 라이브 후 기존 케이스 번호 인용 재신청. 용도 = "자영업 고객 대신 구글 비즈니스 프로필에 소식(localPost) 발행".
- **메타 App Review**: 권한 `instagram_content_publish`·`instagram_basic`·`pages_manage_posts`. 방침 URL 등록 + 시연 영상(로그인→연결→발행) + 권한별 용도 설명 + 앱 라이브 전환. 심사관은 영어 기준 — **방침 페이지에 영문 요약 섹션 권장**.
- **네이버 로그인(네아로) 운영 전환 검수**: 서비스 URL·방침 URL 확인. (블로그/플레이스 발행은 QR 세션 방식이라 심사 무관)
- **카카오 로그인 비즈 앱 검수**: 동의항목 심사, 방침 URL 확인.
