# 핵심 요약

- **S1 변경 가능** = `home.ts hero`의 H1·서브·CTA뿐. **캔버스·격자·두 제품 범례·라벨은 불변.** ⚠️ 좌하단 범례가 이미 "콘텐츠·광고"를 표기 → 서브에서 두 제품 재나열 시 중복.
- **S2** = 현행 Philosophy에서 **MOCKS·지그재그·번호·3막 장문·opening("누구나 마케팅하는 시대")은 제거**, 컨테이너·FadeUp·헤드 스타일은 재사용. 목업 결합이 강해 **S2 전용 경량 컴포넌트 재구성 권장**.
- **길이 위험**: S1 모바일 서브 `max-w-[300px]`(한 줄 ≤약 11자, 초과 시 오버플로) / H1 2줄 이내 / S2 짧은 선언 유지.
- **권장 순서**: S1(데이터만, 저위험) → S2 데이터 shape 결정 → S2 컴포넌트 재구성 → page.tsx 순서 → 렌더 검증 → 금지 게이트.
