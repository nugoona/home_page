# 핵심 요약

- **H1**: 시대 선언 역할 + 브랜드 철학 일치 / PC ≤16자·모바일 ≤11자·2줄 이내 / accent 1곳 / 서브와 반복 없음.
- **서브**: H1 반복 금지, 두 제품/가치 설명 / 코너 범례와 명칭 중복 금지 / PC ≤26자·모바일 ≤18자.
- **CTA**: 명료 + S6과 문구 중복 금지("무료로 시작하기" 2회 방지).
- **게이트**: BRAND_OS §5 금지 9항목 + 구현 체크포인트(home.ts만·구조 무수정·accent 클래스).
- **최종 승인**: 9개 Yes/No 전부 Yes여야 반영 착수. No면 반려 사유만 전달(수정안 대필 금지).

# 아직 비어 있는 항목

- 실제 S1 카피(PM 작성 대기) — 평가 대상이 아직 없음.
