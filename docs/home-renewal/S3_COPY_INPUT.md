## 발주 전제 (모든 블록 공통 — 반드시 지킬 것)

- **중심축 = '이해'** (브랜드 확정): "쉽게·빠르게·AI·자동" 대신 **"맡기던 걸 이제 직접 이해한다"**. 고객 문제(마케팅은 어렵다) 인정 → 이해 → 직접 운영 순서.
- **이 섹션이 증명할 단 하나**: "마케팅은 남에게 맡기는 일이었지만, 이제는 직접 이해하고 운영하는 일이며, 누구나컴퍼니가 그 이해를 돕는다." (제품 기능 소개 아님 — 철학·시대 전환.)
- **두 제품 균형 필수**: 검색 노출(콘텐츠)과 온라인 광고(광고) **어느 한쪽으로 좁히지 말 것**. 현재 홈 철학이 콘텐츠로만 쏠려 있던 게 이번 개편의 이유다.
- **톤**: 품위·열망 공감. 무생물 의인화·목적어 생략 금지. 형용사 대신 명사·상태. 한 줄 15자 안팎. 능동·구체 동사(덜다·걷어내다·되찾다).
- **금지**(어기면 반려): 순위·상위노출·매출·ROAS **보장** / "6곳" 등 채널 수 단정 / **셀프 원클릭 계정연동**("연결은 저희가 돕는다"가 정본) / AI가 "무엇이든 상담"·모든 변경 수행 / **대행사 비난** / **소상공인·영세** / 미출시 기능 / 버즈워드(혁신·솔루션·스마트·원스톱·쉽습니다) / "굴리다" 류 / 모델명(Gemini). 제품명은 "누구나 콘텐츠/누구나 광고", NGN은 로고 전용.
