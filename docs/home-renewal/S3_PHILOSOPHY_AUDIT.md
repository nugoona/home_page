## 3. 정보 중복 표시

- **O ↔ S1 H1**: "누구나 마케팅하는 시대"가 **히어로 H1과 그대로 중복**(HOME_MESSAGE_SYSTEM §4 반복 금지 대상).
- **"노출" 반복**: 1-1 / 1-2 / 1-3 / 2-2 / 3-2 — 검색 노출이 5개 문장에 반복(콘텐츠 편중의 원인이자 결과).
- **"직접 이해·운영/결정은 사장님" 반복**: 2-3 / 3-1 / 3-4 가 같은 공통 철학(직접·주체성)을 세 번 변주. 강조로 볼 수도, 중복으로 볼 수도.
- **"맡기다" 프레임 반복**: 1(title) "남의 일" / 2-3 "맡기는 기술보다" / 3-1 "앱이 맡고" — "맡김" 개념이 3회(1은 부정 과거, 2-3은 대비, 3-1은 앱에 위임의 긍정). 같은 단어가 다른 의미로 쓰여 혼선 소지.

## 4. 논리 흐름(원인 → 변화 → 해결) 끊김 지점

- **뼈대는 존재**: 1막(원인=맡기던 시대) → 2막(변화=규칙이 바뀜) → 3막(해결=직접 하게).
- **끊김 ① 원인이 콘텐츠 전용으로 시작**: 1막이 "상위 노출·광고비·검색 상단"(1-1~1-3)이라 **광고 제품 고객(이커머스 셀러)에게는 원인이 성립하지 않는다.** 공통 철학의 원인이어야 하는데 검색 노출 문제로 좁혀짐.
- **끊김 ② 변화의 '왜 지금'이 약함**: 2막이 "포털 검색이 경험을 본다"까지만 간다. PM이 지목한 **"알고리즘·AI 때문에 직접 이해해야 하는 시대로 바뀌었다"**는 전환 동력이 명시되지 않는다. 검색 알고리즘 얘기만 있고 AI·광고 매체 변화가 빠짐.
- **끊김 ③ 해결이 콘텐츠 기능으로 착지**: 3막이 3-2(검색결과 노출)·3-3(SNS 계정)으로 가면서 **철학 → 제품 기능 설명으로 미끄러진다.** "직접 할 수 있게"의 광고 쪽 해결(쉬운 말로 광고 이해·직접 결정)이 없어 두 제품 공통 해결로 닫히지 못함.
- **결과**: 원인·변화·해결이 **콘텐츠 라인만으로 완결**되고, 광고 라인은 원인부터 해결까지 전 구간 부재 → 두 제품 공통 철학으로서 흐름이 끊긴다.

## 5. 삭제 가능한 문장 (객관 후보 — 판정은 PM)

- **O** (`누구나 마케팅하는 시대`): S1 H1과 중복. 철학 여는 문장을 H1 반복으로 여는 것은 중복 제거 1순위 후보.
- **1-1** (`상위 노출을 위해 광고비 지불`): "상위 노출" 표현 + 콘텐츠 편향 + 광고 제품 고객과 불일치. 다만 "맡기던 시대"의 원인 예시라 완전 삭제 시 원인 근거가 약해질 수 있음(대체 필요 여부는 PM).
- **3-2** (`키워드 검색결과 노출 위치 보여줌`): 철학이 아니라 제품 기능 설명(콘텐츠). S3 뒤 S3 콘텐츠 제품 섹션과 역할 중복 소지 → 철학 섹션에서는 삭제 후보.
- **3-4** (`지름길보다 오래가는 길`) 또는 **2-3**: 공통 철학이 3회 반복되므로 셋 중 하나는 축약 가능(어느 것을 남길지는 PM).

## 6. 반드시 살아남아야 하는 문장/요소 (객관 판단)

- **1막·2막·3막의 3단 뼈대(원인→변화→해결)**: 브랜드 철학의 서사 구조. 순서 자체는 유지 가치.
- **2-3** (`맡기는 기술보다 직접 이해하고 운영`): 공통 철학의 핵심 명제(맡김 → 직접). 브랜드 정체성.
- **3-1** (`어려운 건 앱이 맡고, 결정은 사장님`): "앱은 준비를 돕고 결정은 고객" 철학의 정본 문장(BRAND_OS §2와 정합).
- **3-3** (`콘텐츠는 사장님 계정에 쌓임 · 그 계정은 사장님 것`): "자산은 고객에게 남는다" 철학(BRAND_OS §2). 단 이는 콘텐츠 전용이라, 광고 쪽 대응 가치(직접 이해·결정)가 병렬로 필요.

## 7. 요약 (분석 결론 — 재구성 방향 아님, 사실만)

- 현재 S3는 **원인·변화·해결 3단 서사**를 갖췄으나, **전 구간이 콘텐츠(검색 노출) 라인으로만 완결**되고 광고 라인은 0개다.
- **"왜 지금"(알고리즘·AI로 직접 이해가 필요해진 전환)**이 명시되지 않아 시대 전환의 동력이 약하다.
- 3막 후반이 철학에서 **제품 기능 설명으로 미끄러진다**(3-2·3-3).
- 여는 문장이 **S1 H1과 중복**된다.
- 살아남을 축 = 3단 뼈대 + 공통 철학 3문장(2-3·3-1·3-3). 이 위에 광고 라인과 "왜 지금"을 세우는 것이 재구성의 빈자리(구체 카피는 PM 영역).
