## Phase 2. 섹션별 카피 확정

확정된 구조의 각 슬롯에 들어갈 실제 문장을 정한다. **카피는 ChatGPT가 쓰고, Claude는 슬롯·제약만 제공.**

**대상 섹션**: 확정 6섹션 S1~S6. 슬롯·제약 전체 = `COPY_SLOTS.md`(REQUIRED/OPTIONAL/REMOVE 구분).

**카피 반영 위치 (실행이 어디를 고치는지)**
- **S1 히어로** → `home.ts hero`(H1·sub·cta).
- **S2 공통 철학** → 현행 `philosophy` 3막을 **해체**. 짧은 선언 슬롯을 `home.ts`에 새로 잡거나 `Philosophy.tsx` 재구성(→ COPY_SLOTS S2 판단).
- **S3 콘텐츠 / S4 광고** → ⚠️ 현재 이 자리 카피는 `PhoneScene.tsx`·`AdScene.tsx` **하드코딩**(home.ts `branch` 아님 — §5-1). 제품 철학 문장을 새로 세우므로 컴포넌트/새 슬롯 재구성 필요. RankMock·AdChatMock 내부 문구도 슬롯(COPY_SLOTS S3·S4).
- **S5 회사 약속** → `home.ts promise`(title·sub·log). 타임라인 표시 방식은 결정 대기.
- **S6 CTA** → `home.ts cta`.

**글자 수·레이아웃 제약**
- 줄바꿈은 `<br>`을 문장에 직접 지정(`dangerouslySetInnerHTML`). 헤드=balance, 본문=pretty.
- 서브 텍스트는 **줄간격 촘촘**(leading 1.5~1.55), 자간 -0.01em, PC 16px/모바일 14px.
- 정렬 = 왼쪽정렬 + 블록 중앙(`mx-auto`). `text-center` 금지(철학 opening 제목만 예외).
- **금지 표현 가드레일**(PM_HANDOFF §2) 준수 — 카피 확정 시마다 실행이 게이트 검사.

**완료 조건**
- 모든 섹션 슬롯의 문장이 확정되어 데이터 파일/컴포넌트에 반영 가능한 형태로 정리됨.
- 각 문장이 금지 표현·사실 가드레일 통과(실행이 rg 검사 0건 확인).
- 반복 문구(무료·추가비용·카드불필요) 역할 분담 확정(§5-6).

## Phase 3. 시각물 정합성 수정

카피·구조에 맞춰 이미지·목업을 손본다.

**교체 또는 수정 후보**
- 광고 대시보드 스샷 날짜 불일치(3월 11일 vs 7월 12일 — §5-4) 교체 여부·방법.
- 앱 스샷을 구조 변경에 맞게 재배치/재캡처할지(계정·빌드 확인 필요 — §8-1·8-2).
- RankMock·AdChatMock 내부 카피·수치를 확정 카피에 맞춰 갱신(코드 목업이라 자유 수정 가능).

**실제 화면 vs 코드 목업 구분** (수정 방식이 다름)
- 실제 스샷(app-*.jpg) = **앱 재캡처**만 가능(코드로 못 고침).
- 코드 목업(RankMock·AdChatMock·히어로 캔버스) = **컴포넌트 직접 수정**.

**날짜·데모 데이터 정합성**
- 스샷 내 날짜·계정(`demo-ngn` 등)·수치가 서로 모순 없는지 확인. 측정 표시는 정직하게(순위 보장 금지).

**완료 조건**
- 각 시각물의 "교체/수정/유지" 결정과 방법이 확정됨.
- 실 스샷 교체가 필요하면 재캡처 소스·계정이 확보되거나, 불가 시 대안(코드 목업 대체 등) 결정.

## Phase 5. 렌더 검증

구현이 실제로 의도대로 보이는지 **가장 엄격한 칸까지 올라가** 확인한다(단위·타입 통과만으론 검증 아님).

- **PC**: 실제 브라우저(dev 서버 `localhost:3131`)에서 전 섹션 렌더 — 레이아웃·다크/라이트·시각물 정합.
- **모바일**: 모바일 뷰포트(390 등) — 오버플로 0, 정렬 중앙, 목업 크기, S2 검은 박스가 모바일에만 적용.
- **카피 줄바꿈**: `<br>` 지정대로 PC/모바일 각각 윗줄·아랫줄 균형(balance), 서브 줄간격 촘촘.
- **CTA 링크**: `/start`·`/content`·`/ads` 이동 정상.
- **시각물 정합성**: 스샷 날짜·데모 데이터 모순 없음, 목업 카피가 확정본과 일치.
- **금지 표현 검사**: CLAUDE.md "작업 종료 전 검사" 3종(①순위·금지표현 ②폐기구조 ③파스텔·AI) `rg` 실행 — 잔존 건수·무해 판정 이유 보고, 신규 오염 0.

**완료 조건**
- 위 6개 항목 실측(캡처 포함) 통과. 미검증 항목은 "왜 못 올라갔는지 + 무엇이 미검증인지" 명시.
- 문서 오염 점검(하류만 고치고 상류 방치 금지): 이 문서·PM_HANDOFF·필요 시 DESIGN/CONTENT 정합 갱신.
