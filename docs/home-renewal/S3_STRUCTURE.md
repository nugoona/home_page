## 블록 구조

### 1. Hook
- **역할**: 방문자를 멈춰 세우는 시대·상황 선언 한 방(제품 설명 아님).
- **들어갈 관점**: 공통 철학.
- **최대 문장 수**: 1문장 (헤드).
- **최대 글자 수**: PC 한 줄 ≤20자, 전체 ≤2줄. ⚠️ S1 H1과 중복 금지.

### 2. Problem
- **역할**: 기존 방식(맡기던 시대)의 한계를 짚는 영역.
- **들어갈 관점**: 공통 철학 (콘텐츠·광고 **둘 다에 성립**하는 원인이어야 함 — 검색 전용으로 좁히지 않음).
- **최대 문장 수**: 2~3문장.
- **최대 글자 수**: 문장당 PC ≤30자 / 모바일 ≤20자.

### 3. Turning Point
- **역할**: "왜 지금 바뀌었는가"의 전환 동력을 제시하는 영역(알고리즘·AI로 직접 이해가 필요해진 전환).
- **들어갈 관점**: 공통 철학 (전환의 근거는 공통, 예시로 콘텐츠·광고 각각을 짧게 병렬 가능).
- **최대 문장 수**: 2~3문장.
- **최대 글자 수**: 문장당 PC ≤30자 / 모바일 ≤20자.

### 4. Solution
- **역할**: "그래서 직접 할 수 있게 만들었다"는 회사의 답 — 두 제품이 각각 어떻게 그 철학을 실현하는지 **균형 있게**.
- **들어갈 관점**: 공통 철학(주제문) + **콘텐츠 1 + 광고 1**(각 제품이 철학을 실현하는 관점, 기능 나열 아님).
- **최대 문장 수**: 3~4문장(공통 1 + 콘텐츠 1 + 광고 1 + 마무리 1).
- **최대 글자 수**: 문장당 PC ≤30자 / 모바일 ≤20자.

### 5. Closing
- **역할**: 철학을 한 문장으로 봉인하는 마무리(다음 제품 섹션으로 넘기는 다리).
- **들어갈 관점**: 공통 철학.
- **최대 문장 수**: 1문장.
- **최대 글자 수**: PC ≤24자, ≤2줄.
