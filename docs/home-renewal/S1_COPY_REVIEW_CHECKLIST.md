# S1 히어로 카피 평가표

> **목적**: PM(ChatGPT)이 작성한 S1 카피를 구현 전에 객관적으로 검증하는 평가 기준. **평가 기준만** — 카피 작성·수정 제안·구현 없음.
> **근거**: `BRAND_OS.md`·`HOME_MESSAGE_SYSTEM.md`·`COPY_SLOTS.md`·`S1_S2_IMPLEMENTATION_GUIDE.md`·`COPY_IMPLEMENTATION_PLAN.md`.
> **사용법**: 각 항목을 카피안에 대입해 통과/실패를 표시. 하나라도 실패면 §6 최종 승인 불가.

---

## 1. H1 평가 기준

### 브랜드 일치
- 홈 단 하나의 메시지("마케팅은 맡기는 게 아니라 직접 이해·운영, 두 제품이 돕는다")의 **시대 선언** 역할에 부합하는가.
- BRAND_OS 철학(직접·이해)과 어긋나지 않는가.
- 성과·순위를 암시하지 않는가(선언이지 약속이 아님).

### 글자 수
- PC: 한 줄 기준 **≤16자** 권장(`clamp` 최대 60px, `leading-1.1`).
- 모바일: 한 줄 **≤11자** 권장(`clamp` 최소 28px). 초과 시 `<br>`로 줄을 직접 끊었는가.
- **전체 2줄 이내**인가(3줄 이상이면 content rect 상하 12.5% 안에서 sub·CTA와 세로 충돌).

### 차별성
- 흔한 SaaS 관용구("쉽고 빠르게" 류)가 아닌, 누구나컴퍼니만의 관점(진입장벽·직접 운영)이 드러나는가.

### 반복 여부
- accent `<span class="text-accent">…</span>`가 **1곳**인가(강조 1곳 원칙).
- H1이 서브에서 되풀이되지 않는가(현행 결함: opening이 H1 반복).

---

## 2. 서브 평가 기준

- **역할**: H1을 풀어 쓰는 게 아니라 **두 제품/고객 가치를 설명**하는가(현행 결함 5-3 해소).
- **범례 중복**: 좌하단 코너 범례가 이미 "콘텐츠·광고"를 표기 → 서브에서 두 제품명을 **또 나열하지 않는가**(개념은 설명하되 명칭 나열 지양).
- **글자 수**: PC 각 줄 **≤26자**, 모바일 각 줄 **≤18자**(모바일 `max-w-[300px]` 폭). 초과 줄은 `<br>` 제어했는가.
- **줄 수**: 2~3줄 권장. `<br>` 지정 시 PC/모바일 각각 윗줄·아랫줄 길이 균형(balance).
- **톤**: 쉬운 말·현재형·정직(BRAND_OS §6). 과장·미래 보장 없음.

---

## 3. CTA 평가 기준

- **명료성**: 버튼만 봐도 다음 행동이 분명한가.
- **글자 수**: 짧게(버튼 `px-8` 고정, 라벨 길면 모바일 가로 여백 압박, 줄바꿈 불가).
- **역할 분담**: S6 CTA와 문구가 **중복되지 않는가**("무료로 시작하기"가 S1·S6 2회면 반복 금지 위반 — HOME_MESSAGE_SYSTEM §4).
- **링크 정합**: `ctaHref` 목적지(현행 `/start`)가 카피 약속과 일치하는가.

---

## 4. 구현 체크포인트

- H1/서브/CTA가 **`home.ts hero`에만** 반영되는가(HeroB 구조 무수정).
- `<br>`은 문장 안에 직접, `dangerouslySetInnerHTML`로 렌더되는 순수 텍스트인가(스크립트·외부 태그 없음).
- accent는 `<span class="text-accent">`만 사용(인라인 hex·임의 색 금지).
- 캔버스·격자·범례·라벨·스크롤 트랙은 **건드리지 않는가.**
- 모바일 서브 `max-w-[300px]`·H1 `clamp` 최소값에서 오버플로 없는가(렌더로 확인 전제).

---

## 5. 금지 표현 체크리스트 (BRAND_OS §5)

- [ ] 순위·상위노출·매출·조회수·ROAS **보장/개선** 표현 없음.
- [ ] 현재 라이브 범위를 넘는 **채널 수 단정**("6곳" 등) 없음.
- [ ] **셀프 원클릭 계정 연동** 표현 없음.
- [ ] AI가 **무엇이든** 한다는 표현 없음.
- [ ] **대행사 비난** 없음.
- [ ] **소상공인·영세** 등 표현 없음.
- [ ] **미출시 기능**을 현재처럼 말하지 않음.
- [ ] **모델명(Gemini 등)** 노출 없음.
- [ ] 제품명은 "누구나 콘텐츠/누구나 광고", NGN은 로고 전용(H1/서브에 NGN을 제품명으로 쓰지 않음).

---

## 6. 최종 승인 체크리스트 (Yes / No)

- [ ] H1이 시대 선언 역할 + 브랜드 철학 일치 — **Yes / No**
- [ ] H1 글자 수·줄 수(PC ≤16자, 모바일 ≤11자, 2줄 이내) 충족 — **Yes / No**
- [ ] H1 accent 1곳, 서브와 반복 없음 — **Yes / No**
- [ ] 서브가 H1을 반복하지 않고 두 제품/가치를 설명 — **Yes / No**
- [ ] 서브가 코너 범례와 명칭 중복 없음 — **Yes / No**
- [ ] 서브 글자 수·줄 수(PC ≤26자, 모바일 ≤18자) 충족 — **Yes / No**
- [ ] CTA가 명료하고 S6과 문구 중복 없음 — **Yes / No**
- [ ] 구현 체크포인트(home.ts만·구조 무수정·accent 클래스) 충족 — **Yes / No**
- [ ] 금지 표현 9개 항목 전부 통과 — **Yes / No**

> 전 항목 **Yes**여야 실행(Claude)이 반영 착수. 하나라도 No면 PM에게 반려 사유만 전달(수정안 대필 금지 — 카피는 PM 영역).
