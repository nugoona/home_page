## 2. 섹션별 카피 후보 (애플/Vercel 톤·현재형)

### 1. 히어로
- 헤드라인 A: 가게 이름만 넣으세요. 나머지는 누구나 컨텐츠가 합니다.
- 헤드라인 B: 발행하고 끝이 아닙니다. 노출됐는지 보여드립니다.
- 서브: 상호명만 넣으면 메뉴·소개·키워드가 자동으로 채워집니다. 사진 한 장이면 AI가 글을 쓰고, 네이버 블로그·플레이스·인스타·페이스북·구글까지 한 번에 발행합니다. 그리고 내 글이 지금 몇 페이지에 있는지, 매달 리포트로 확인하세요.
- CTA(주): 1개월 무료로 시작 (카드 필요 없음) · CTA(보조): 작동 방식 보기

### 2. 30초 시작 (온보딩 자동 프리필) ★
- 헤드라인: 설정할 게 없습니다. 가게 이름이면 됩니다.
- 본문: 상호명을 넣는 순간 네이버에서 메뉴·업종·지역·소개를 가져와 자동으로 채웁니다. 검색에 쓸 키워드도 함께 골라 둡니다. 사장님은 확인만 하세요.

### 3. 문제 정의
- 헤드라인: 블로그 대행에 매달 30만 원. 그런데 효과는 느껴지시나요?
- 본문: 대부분의 대행은 글을 올려주고 끝입니다. 얼마나 노출됐는지는 보여주지 않죠. 그래서 매달 돈을 쓰면서도 확신이 없습니다.
- 전환: 누구나 컨텐츠는 반값 이하로, 증거까지 드립니다.

### 4. 작동 방식 3스텝
- 01 올리세요: 사진과 짧은 메모. 말로 하셔도 됩니다.
- 02 AI가 씁니다: 사장님 목소리로, 손님이 검색하는 말을 담아.
- 03 자동으로 발행됩니다: 네이버 블로그·플레이스·인스타·페이스북·구글 비즈니스·유튜브 쇼츠에 맞춰 각각.
- 하단: 레시피도, 손님 얼굴도, 영업 비밀도 필요 없습니다. 부담 없이 줄 수 있는 것만.

### 5. 1년치 글감 ★
- 헤드라인: 무슨 글을 쓸지, 이제 고민하지 마세요.
- 본문: 1년치 글감을 업종에 맞게 미리 짜 드립니다. 매주 한 장씩, 오늘 뭘 올릴지 알려드립니다. 사진만 더하면 글이 됩니다.

### 6. 핵심 차별점 (증거) — 최대 무기
- 헤드라인: 남들은 발행만 합니다. 우리는 노출을 증명합니다.
- 카드 1 — 실검색량 기반: 감이 아니라 데이터로. 손님이 실제로 검색하는 말을 찾아 담습니다.
- 카드 2 — 페이지 순위 추적: 내 글이 지금 몇 페이지에 있나. 계속 확인합니다.
- 카드 3 — 월간 노출 리포트: 꾸준함과 성과를 매달 한눈에.
- 강조: 효과가 안 느껴져 그만두는 게 아니라, 효과를 눈으로 보고 계속하게.

### 8. 가격 (섹션 카피)
- 헤드라인: 대행사 한 달 값이면, 1년을 씁니다.
- 서브: 약정 없음. 1개월 무료. 카드도 필요 없습니다.

### 9. 비교
- 헤드라인: 대행 월 30만 vs 누구나 컨텐츠 월 9.9만.
- 서브: 같은 일을 반값 이하로. 게다가 증거까지.

### 12. 마감 CTA
- 헤드라인: 오늘 가게 이름 하나부터.
- 버튼: 1개월 무료로 시작 · (카드 필요 없음)
- 크로스셀: 광고까지 필요하세요? → 누구나 대시보드 보기

## 4. 차별점 3줄 (증거 기반)
1. **이름 하나로 시작**: 상호명 자동 프리필 — 설정 부담 0, 진입 30초.
2. **소재 걱정 없음**: 1년치 글감을 알아서, 사진·메모(또는 음성)만 더하면 다채널 발행.
3. **증거를 보여줌**: 페이지 순위 추적 + 월간 리포트로 "효과 미체감"(대행 이탈 1위)을 정면 방어 — 최대 무기.

## 6. SEO 온페이지 계획

- **Title:** 네이버 블로그 자동 발행 + 노출 최적화 | 누구나 컨텐츠 (월 9.9만~, 약정 없음)
- **Meta:** 가게 이름만 넣으면 메뉴·키워드가 자동으로 채워집니다. 사진 한 장이면 AI가 글을 쓰고 네이버·인스타·페이스북에 발행합니다. 실검색량 노출 최적화·페이지 순위 추적·월간 리포트. 블로그 대행 월 30만의 대안, 1개월 무료.

- **H1:** 가게 이름만 넣으면, 네이버 블로그가 자동으로 채워집니다.
- **H2 + 키워드:**
  - "블로그 대행 대신, 자영업 SNS 자동화" — `블로그 대행 대안`·`자영업 SNS 자동`
  - "네이버 검색 노출, 데이터로 최적화" — `소상공인 네이버 노출`·`네이버 상위노출 직접`
  - "AI가 쓰고 자동으로 발행" — `AI 블로그 발행`·`네이버 블로그 자동`
  - "1년치 글감 자동 제안" — `블로그 글감`·`자영업 콘텐츠`

## 8. 정직 원칙 체크리스트 (완성 전제여도 반드시 지킴)

> 진행상태("미완/베타/연결 시")는 홈페이지에서 쓰지 않는다(완성 전제). 아래는 그와 별개로 **완성돼도 지켜야 할 사실·정책 가드레일**.

- **"네이버 1등/상위노출 보장", "1페이지 보장" 금지** — 네이버 정책·현실상 보장 불가. "노출 최적화 / 순위 추적 / 직접 관리"까지만.
- **"최저가/업계 최고/1위" 류 금지** — 검증 불가 우월 주장.
- **없는 기능·없는 후기·없는 고객사 로고 지어내기 금지** — 신뢰 섹션은 확보된 것만.
- **AI 글은 업체 본인 시점** — 방문객·체험단 위장 카피 금지.
- **"카드 미요구 무료체험"은 진짜여야 함** — 카피에 쓴 이상 실제로 카드 없이 시작 가능(기획-구현 일치).
- **가격 앵커(대행 30~90만)는 시장 사실로만** 제시 — 특정 경쟁사 비방 금지.
