# ⭐ 정직 현황 스냅샷 (홈페이지 공개 전 대조용 — 카피 아님)

> **출처: `ngn_upload/docs/STATUS.md` "채널·기능 완성도 보드" (2026-07-11 기준). 채널 상태가 바뀌면 그 보드를 다시 볼 것.**
> ⚠️ **이 블록은 카피 재료가 아니다.** 아래 §0~§8 본문은 "완성 전제·현재형" 원칙으로 쓰여 미완 기능도 "된다"로 서술한다. 그건 카피 어감용이고, **실제로 홈페이지에 공개·광고하기 전엔 반드시 이 스냅샷과 대조**해서 "지금 진짜 되는 것만 완성 채널로 광고"해야 한다. 과거에 이 구분을 안 지켜 진행 중 채널(플레이스·구글비즈니스·유튜브)을 "완성"으로 오독·과장한 사고가 있었다(STATUS 보드 범례·§홈페이지 출시 선행조건 참조). 이 블록이 그 재발 방지 가드다.

## 1. 한 줄 소개 (사장님 언어)
가게 이름만 대면 AI가 알아서 가게를 조사하고, 사진 몇 장과 짧은 메모(또는 음성)만 올리면 사장님 목소리로 글을 써서 네이버 블로그·인스타그램·페이스북에 자동으로 올려 줍니다. 손님 리뷰 답글 초안까지 도와줍니다. **사장님이 SNS에 손대지 않아도, 검색하면 우리 가게가 꾸준히 보이게.**

## 2. 핵심 가치 (왜 필요한가 — 고통 → 해결)
- **고통**: 자영업 사장님은 SNS가 매출에 중요한 걸 알지만 장사가 바빠 손댈 시간이 없다. 매번 글 쓰는 게 부담이고, 무슨 글을 올릴지 소재도 금방 마른다.
- **해결(가장 큰 만족)**: **"내가 글 안 써도 SNS 운영이 됨" = 시간 절약.** 입력은 "가게 이름 하나"에서 시작하고, 나머지는 앱이 채운다. (근거: `project_app_value_proposition`)
- **북극성 = 일관성(꾸준한 업로드).** 상위노출·조회수를 약속하는 앱이 아니다. 꾸준히 올리면 → 블로그·인스타 **계정 등급이 올라가고** → 게시글의 키워드가 손님 검색에 **자연 노출**된다. 사장님이 가장 원하는 단 하나 = **"검색하면 우리 가게 콘텐츠가 보이느냐."** (근거: `project_north_star_exposure_cadence`)
  - ⛔ **그래서 "검색 1위/상위노출/1페이지 보장"은 절대 카피에 쓰지 않는다.** 우리는 글을 만들고 발행·측정할 뿐, 네이버·구글 순위를 보장하지 않는다(정책·현실상 불가). "노출 최적화 / 순위 추적 / 직접 관리"까지만.

## 3. 주요 기능 (고객 언어, 1~2줄씩)
| 기능 | 고객이 얻는 것 |
|---|---|
| **가게 이름 자동 채움(온보딩)** | 상호명만 넣으면 네이버에서 메뉴·업종·지역·소개·키워드·썸네일까지 앱이 다 채운다. 사장님이 하는 일은 이름 입력 + 후보에서 내 가게 고르기 + "맞아요" 탭뿐. |
| **1년치 글감 자동 제안** | 무슨 글을 쓸지 고민할 필요 없이, 업종에 맞춰 1년치 주제를 짜 준다(주 1회 한 장씩). "소재가 마른다"를 해결. |
| **AI 글 작성** | 사진과 메모만 올리면 사장님 목소리로 글이 완성된다(인사말 없이 현장부터, 손님·체험단 위장 없음). |
| **사진 질문(Q&A)** | 올린 사진을 보고 딱 필요한 것만 물어 글 재료를 채운다(저부담 입력). |
| **음성으로 올리기** | 타이핑이 번거로우면 말로 하면 AI가 정리해 글로 만든다. |
| **검토·직접 편집·"말로 수정"·썸네일** | 발행 전 폰에서 확인하고, "여기 이렇게 바꿔줘"라고 말하면 고쳐 준다. 대표 썸네일도 자동 생성 후 칸 편집 가능. **모든 글은 사장님 승인 후에만 발행**(무단 발행 없음). |
| **다채널 동시 발행** | 한 번 올리면 켜 둔 채널마다 그 채널에 맞는 글로 갈라져 자동 게시(팬아웃). |
| **꾸준한 발행 일정** | 승인된 글이 채널당 하루 1건씩, 사장님이 정한 빈도(주 N회)에 맞춰 자동으로 줄 서서 게시. 시각은 시스템 배정. |
| **검색 키워드 자동 생성·발행 합류** | 손님이 실제 검색하는 말(지역+업종)을 검색량 데이터로 찾아 글 제목·태그·해시태그에 자동으로 싣는다. |
| **페이지 순위 추적** | 뽑은 키워드로 우리 가게가 지금 검색 몇 페이지에 있는지 매일 재어 카드로 보여준다(하락 경고만, "등수 올려줌" 아님). |
| **노출 소식 자동 반영(킬러)** | 네이버·인스타·구글 등의 노출 규칙 변화를 주 1회 대신 챙겨, 도움 되는 건 앞으로 쓰는 글에 알아서 녹인다. "노출 방식이 바뀌어도 알아서 따라간다." |
| **리뷰 답글 초안** | 배민·쿠팡 리뷰를 붙여넣으면 사장님 시점 답글 초안을 만들어 준다(앱이 자동 등록은 안 함, 초안 복사만). |
| **여러 가게 한 계정** | 매장이 여럿이어도 로그인 하나로 관리. |
| **주인 액션 안내** | AI가 자동으로 못 하는 것 중 노출에 필요한 건 사장님에게 알려 준다. |

## 4. 지원 채널 표 (정직 — ✅라이브 / 🟡진행 중 / ⬜예정)
> 🟡 = 코드는 있으나 발행 게이트 off 또는 외부 승인 대기 = **진행 중이지만 아직 실발행 안 됨.** **"완성 채널"로 광고하면 과장.** "곧 지원 / 준비 중"으로 표기하거나 카피에서 제외.

| 채널 | 상태 | 홈페이지 표기 |
|---|---|---|
| 네이버 블로그 | ✅ **라이브** | 광고 가능 (단, 업체마다 운영자 QR 세션 연결 필요) |
| 인스타그램 | ✅ **라이브** | 광고 가능 (메타 검수 + 업체 비즈계정 연결 필요) |
| 페이스북 | ✅ **라이브** | 광고 가능 (위 메타 조건 동일) |
| 네이버 플레이스 소식 | 🟡 **진행 중** | **완성으로 광고 금지.** 게이트 off(발행 DOM 선택자 미확정). 공개 전 실작동 필수 |
| 구글 비즈니스 포스트 | 🟡 **진행 중** | **완성으로 광고 금지.** GBP API 승인 대기(케이스 진행 중) + 게이트 off |
| 유튜브 쇼츠 | 🟡 **진행 중** | **완성으로 광고 금지.** per-tenant 셀프연결 UI 미구현 |
| 카카오채널 알림 | ⬜ **예정** | 미착수 — 카피·목업에서 제외 |
| 리뷰 답글 — 배민·쿠팡(붙여넣기 초안) | ✅ **라이브** | 광고 가능 (초안 생성만, 자동 등록 아님) |
| 리뷰 답글 — 구글·네이버 플레이스(자동수집) | ⬜ **예정** | **광고 금지** — 미구현. "정본에 없으면 없는 것" |

**한 줄 정직 요약**: 지금 **진짜 발행되는 건 네이버 블로그·인스타그램·페이스북 3채널**(그것도 업체별 외부 연결 필요). 플레이스·구글 비즈니스·유튜브는 **진행 중**(발행 게이트/외부 승인 대기), 카카오만 예정.

## 5. 홈페이지에 넣을 때 주의사항 (다음 세션 실수 방지)
1. **채널 과장 금지 = 최우선.** §4 표에서 🟡·⬜인 채널(플레이스·구글비즈니스·유튜브·카카오·자동 리뷰수집)을 "완성/지금 됩니다"로 광고하지 말 것. STATUS 보드 §"홈페이지 출시 선행조건": 이 핸드오프 본문(§0·§2·§3)이 플레이스·구글비즈니스·유튜브 발행을 "완성 채널"로 쓰고 있어, **홈페이지 공개 전 이 3개 실작동이 선행조건**이다. 안 되면 카피에서 빼거나 "곧 지원"으로.
2. **순위·성과 보장 금지.** "검색 1위/상위노출/1페이지 보장", "매출·조회수·구독자 상승 보장" 전부 금지. 순위 추적은 **측정·표시**일 뿐. (근거: `features-master-2apps.md` 전역 금지표현)
3. **"사진 한 장" 금지.** 블로그 발행은 **유효 4장(서로 다른 장면)** 게이트. "사진 한 장이면 블로그"는 틀림. "이미지 1장"은 광고·플레이스 소식에만. (근거: `features-master-2apps.md` ★채널별 사진 수)
4. **AI 엔진 = 'Claude'로 통일** 표기(내부 모델명 노출 금지).
5. **AI 글은 업체 본인 시점.** 방문객·체험단 위장 카피 금지.
6. **"카드 미요구 무료체험"은 진짜여야** 함(기획-구현 일치).
7. **"소상공인" 화면 카피 금지**(→"가게 사장님"). SEO 검색어 문자열로만 §6에서 유지.
8. **월간 노출 리포트는 /content에서 제거**(대시보드 기능, 콘텐츠 앱 정본에 없음 — 순위 추적이 증명 대신). 자세히는 아래 v3 노트 참조.
9. **자동 등록 오해 금지.** 리뷰 답글은 모든 채널에서 **초안만**, 사장님이 복사해 붙여넣는다. "네이버·구글은 앱이 답글을 달아 준다"는 사실 아님.

## 8. 정직 원칙 체크리스트 (완성 전제여도 반드시 지킴)

> 진행상태("미완/베타/연결 시")는 홈페이지에서 쓰지 않는다(완성 전제). 아래는 그와 별개로 **완성돼도 지켜야 할 사실·정책 가드레일**.

- **"네이버 1등/상위노출 보장", "1페이지 보장" 금지** — 네이버 정책·현실상 보장 불가. "노출 최적화 / 순위 추적 / 직접 관리"까지만.
- **"최저가/업계 최고/1위" 류 금지** — 검증 불가 우월 주장.
- **없는 기능·없는 후기·없는 고객사 로고 지어내기 금지** — 신뢰 섹션은 확보된 것만.
- **AI 글은 업체 본인 시점** — 방문객·체험단 위장 카피 금지.
- **"카드 미요구 무료체험"은 진짜여야 함** — 카피에 쓴 이상 실제로 카드 없이 시작 가능(기획-구현 일치).
- **가격 앵커(대행 30~90만)는 시장 사실로만** 제시 — 특정 경쟁사 비방 금지.
