# [전달문] 챗봇 "운영팀 전달" 기능 — 대시보드 프로젝트 요건

> 발신: ngn_homepage 요금제 전략 세션 (2026-07-20, CEO 확정) · 수신: **ngn_dashboard 세션**
> 이 문서는 자족적이다 — 배경·정책·요구 기능이 전부 이 안에 있다. 구현 상세(UI·스키마)는 대시보드 세션 재량.

## 1. 배경 — 회사 상담 정책 (CEO 확정 2026-07-20)

- **전화·실시간 상담 = 안 한다** (수시 응대는 리소스의 90%를 먹는다 — CEO 확정 운영 철학). 대표번호는 화면에서 내리는 방향.
- 상담 깔때기: **1선 = 앱 내 AI 챗봇(즉답)** → **2선 = 챗봇 안 "운영팀 전달"(비동기 티켓, 영업일 24시간 내 답변)**. 카카오톡 채널은 자동응답 이정표만(상담원 연결 없음). 계정 연결 등 실시간 필수 작업은 예약제.
- 장애·실패는 문의받기 전에 **앱이 먼저 알림**(문의량 원천 감소).
- **티어 차별(CEO 확정)**: 카카오톡 직통 상담은 **콘텐츠 프리미엄(월 49만) 전용 혜택**. 대시보드(누구나 광고) 고객의 사람 문의 경로는 이 "운영팀 전달"이 유일하다.

## 2. 요금 정책 컨텍스트 (챗봇 관련)

- 누구나 광고 = **월 19.9만 단일 요금제**(전 기능. 티어 없음) + 비즈니스(문의). 근거 = `ngn_homepage/docs/랜딩-아이디어로그.md` 결정 로그 "요금제 전략 확정 2026-07-20".
- 챗봇은 Claude API 실원가가 들므로 **전 고객 동일한 일일 사용 상한(fair-use)** 을 둔다 — 요금제 차별이 아니라 서비스 보호. 상한값은 출시 후 사용 로그 보고 조정(초안 감각: 하루 수십 회 단위, 어뷰징 방어 목적이라 일반 사용자는 체감 없어야 함). 상한 도달 시 안내 문구 필요("내일 다시" + 급한 건 운영팀 전달).

## 3. 요구 기능 — 챗봇 내 "운영팀 전달"

**트리거**
- 챗봇 대화 중 상시 진입 가능(버튼) + 챗봇이 못 푸는 상황(외부 안내 코스로 빠질 때·같은 질문 반복 시)에 챗봇이 먼저 제안: "운영팀에 전달할까요?"

**티켓에 자동 첨부할 것 (핵심 — 이게 응대 시간을 반의반으로 줄인다)**
- 최근 대화 내용(맥락), 업체/계정 식별자, 문의 시점 화면·기능 맥락(가능하면), 고객이 답 받을 경로.

**전달 경로**
- 운영자(대표) **텔레그램 봇 알림**으로 발송. ※ nugoona 문의 알림의 Slack→Telegram 이전 건(미착수, 구 Slack webhook 폐기 포함)과 같은 인프라로 묶어 처리 권장.

**답변 회신**
- 앱 내(챗봇 대화 이어붙이기 또는 알림)로 회신. 이메일 병행은 대시보드 세션 판단.
- 고객 노출 문구(약속): **"운영팀이 확인 후 영업일 24시간 안에 답변드립니다."** — 즉시 응답 기대를 만들지 않는 것이 정책의 핵심.

**남용 방지**
- 업체당 열린 티켓 수 제한 등 가벼운 가드(상세 재량).

## 4. 금지·주의

- "전화 상담·실시간 상담" 기대를 만드는 문구 금지(전화번호 노출, "바로 연결" 류).
- 티켓 기능이 챗봇보다 앞에 보이면 안 됨 — 챗봇이 1선, 전달은 챗봇을 거친 2선.
- 홈페이지 공개 약속과 충돌 금지: 월 정액·수수료 없음·기능 추가에 추가 비용 없음.
