# /content(누구나 콘텐츠) 빌드 — 4주체 협업 로그

> **목적**: /content 페이지를 만드는 과정에서 **4주체(사장님 · GPT · Opus(메인) · 페이블(Fable 5))**가 주고받는 결정·검증을 시간순으로 남긴다. 세션이 바뀌거나 컴팩션돼도 "누가 무엇을 왜 결정했는지"가 유실되지 않게 한다.
> **관할**: 이 파일은 **과정 기록(로그)**이다. 확정된 규칙·톤·좌표는 `nugoona/DESIGN.md`, 카피는 `nugoona/lib/content/content.ts`, 세션 상태는 `.ngn-session.md`가 정본 — 여기 로그와 정본이 어긋나면 정본이 이긴다.
> **기록 규칙**: 새 주고받음이 생길 때마다 아래에 append(최신이 위). 각 항목 = [주체] 무엇을 → [검증 주체] 판정.

## 4. 히어로 홈 재탕 지적 → 벤치마크 조사
