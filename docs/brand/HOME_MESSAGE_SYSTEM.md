## 1. 홈페이지가 전달해야 하는 단 하나의 메시지

**"이제 마케팅은 남에게 맡기는 게 아니라, 사장님이 직접 이해하고 운영하는 일이며, 누구나컴퍼니의 두 제품(콘텐츠·광고)이 그걸 돕는다."**

(위 1문장은 홈 전체가 수렴해야 하는 메시지 목적이며, 슬로건·헤드라인 카피가 아니다.)

## 2. 방문자가 S1~S6를 지나며 단계별로 이해해야 하는 것

> 카피 아님 — 각 섹션을 지난 뒤 방문자의 머릿속에 남아야 하는 "이해".

- **S1 (시대 선언)**: "마케팅을 직접 운영하는 시대가 왔고, 이 회사는 검색 노출과 온라인 광고 두 가지를 돕는 회사구나."
- **S2 (회사가 태어난 이유·공통 철학)**: "문제는 마케팅 자체가 아니라 계정·용어·설정의 진입장벽이었고, 이 회사는 앱이 준비·이해를 돕되 결정은 내가 하게 만드는구나."
- **S3 (누구나 콘텐츠)**: "시간이 없어도 콘텐츠가 채널별로 만들어지고, 검색 노출을 정직하게 확인할 수 있으며, 그 자산은 내 계정에 남는구나."
- **S4 (누구나 광고)**: "어려웠던 광고를 쉬운 말로 이해하고, 성과를 한 화면에서 보며, 연결은 도와주니까 내가 직접 결정할 수 있겠구나."
- **S5 (회사 약속)**: "매체가 바뀌어도 앱이 계속 따라가고, 기존 고객인 나는 추가 비용 없이 계속 쓸 수 있구나."
- **S6 (CTA)**: "부담 없이 한 달 먼저 시작해볼 수 있고, 시작 준비까지 도와주는구나."

**흐름의 논리**: 시대(왜 지금) → 이유(왜 우리) → 제품A(무엇을 콘텐츠로) → 제품B(무엇을 광고로) → 지속(믿어도 되는 이유) → 행동(시작). 제품(S3·S4)보다 이유(S2)가 먼저 온다.

## 3. 콘텐츠와 광고의 공통 철학 / 차이점

### 공통 철학 (S2에서 선언, 두 제품이 공유)
- 진입장벽(계정·용어·설정)을 낮춘다.
- 앱은 준비·이해를 돕고, **결정은 고객이** 한다.
- 종속시키지 않고 스스로 운영하게 한다.
- 과장·성과 보장 없이 **정직**하게.
- 상품·서비스는 고객이 가장 잘 안다.

### 차이점

| 축 | 누구나 콘텐츠 (S3) | 누구나 광고 (S4) |
|---|---|---|
| 고객 | 시간 없는 스토어·서비스업 사장님 | 광고가 필수인 이커머스 셀러·브랜드 |
| 가장 큰 문제 | 꾸준한 발행·검색 노출을 챙길 시간·방법 부재 | 계정·용어·설정이 어려워 직접 운영·성과 확인이 막힘 |
| 앱이 하는 일 | 채널별 글 생성·발행 + 노출 정직 측정 | 소재 제작 + 통합 성과 + 쉬운 말 챗봇 |
| 남는 가치 | 자산이 **내 계정**에 쌓인다 | 어려운 광고를 이해하고 **직접 결정**한다 |
| 증거 시각물 | RankMock(노출 측정) | AdChatMock(쉬운 말 챗봇) |

## 4. 절대 반복하면 안 되는 메시지 (홈 전체에서 중복 시 힘이 빠짐)

- **"무료"** — 현재 S1 CTA + S6 primary로 2회. → 반복 금지, 역할 분담.
- **"추가 비용/추가 요금 없음"** — 현재 S5에서 3회(sub·강조·부연). → 강조 1곳만.
- **"카드 등록 없음 / 약정 없음"** — S6 헤드·서브 중복. → 각 1회.
- **"직접"** — 철학의 핵심어지만 매 섹션 남발하면 마모됨. → 의미가 필요한 지점에만.
- **H1 문장("누구나 마케팅하는 시대")의 되풀이** — 현재 S1 H1과 옛 철학 opening이 겹침. → S1에서만.

## 5. 홈페이지 전체에서 반드시 "한 번만" 말해야 하는 메시지

- **회사가 태어난 이유**(진입장벽 관점) → S2에서 한 번, 무겁게.
- **"결정은 고객이 한다"의 공통 철학 선언** → S2 (제품 섹션에선 각 제품 방식으로 변주하되 재선언하지 않음).
- **"추가 비용 없음" 정책 강조** → S5 한 곳.
- **무료 체험 조건(한 달·카드·약정)** → S6에 각 1회.
- **매니지드 온보딩(연결을 도와줌)** → 광고(S4) 또는 CTA(S6) 중 한 곳에서 명확히. (셀프 원클릭 아님을 여기서 못박음)

## 6. 홈페이지 전체에서 "여러 번 반복해도 되는" 메시지

> 브랜드 정체성을 강화하는 축이라, 표현을 바꿔가며 반복 가능(같은 문장 복붙이 아니라 변주).

- **"직접 이해하고 운영한다"**는 태도 — 각 섹션이 자기 방식으로 보여줘도 됨(S2 선언 → S3 콘텐츠로 → S4 광고로).
- **"정직·측정"** — 과장 없이 현황을 보여준다는 태도(S3 노출 측정, S4 쉬운 말 성과 설명).
- **"두 제품(콘텐츠·광고)"의 대비 구조** — S1 범례, S3/S4 분리, 색 체계(#4d9fff/#29d5ff)로 반복 강화.
- **"고객 편"의 주어** — "앱이 돕고 결정은 고객"이라는 시점은 반복될수록 좋다.
