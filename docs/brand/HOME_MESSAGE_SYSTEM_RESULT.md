- **홈 단 하나의 메시지**: 마케팅은 맡기는 게 아니라 사장님이 직접 이해·운영하는 일이며, 두 제품(콘텐츠·광고)이 그걸 돕는다.
- **흐름 논리**: 시대(S1) → 이유·공통 철학(S2) → 콘텐츠(S3) → 광고(S4) → 지속 약속(S5) → 행동(S6). 제품보다 이유가 먼저.
- **반복 규칙 확정**: "무료·추가 비용 없음·카드/약정·직접·H1 되풀이"는 반복 금지 / "회사 태생 이유·공통 철학 선언·추가 비용 정책·무료 조건·매니지드"는 한 번만 / "직접 운영 태도·정직·측정·두 제품 대비·고객 편 주어"는 변주 반복 가능.
