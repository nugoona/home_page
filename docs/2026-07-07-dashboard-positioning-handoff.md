## A. 북극성 · 포지셔닝

- **한 사이트 2갈래 중 대시보드 = 광고(/ads) 경로.** (노출이 먼저면 업로드 — 크로스셀 한 줄만.)
- **북극성:** 대행 알아보던 규모 있는 셀러·브랜드가 30초 만에 "직접 해도 되겠고, 한 달 공짜니 밑질 것 없다." (⛔"소상공인" 화면 카피 금지 — 대시보드 타깃은 자체 직원이 운영하는 셀러·브랜드)
- **차별화 무게 = "집행 대체"가 아니라 "통합·이해".** 광고 만들기·운영도 제품 기능이지만(집행은 플랫폼도 함), 해자는 **매출까지 합친 통합 뷰 + 어려운 숫자를 사람 말로 풀어주는 것**.
- **한 줄 요지:** "대행사 없이 직접 하되, 흩어진 성과를 한 화면에서 이해한다."

## B. 앱 전체 기능 인벤토리 (완성 전제·현재형 · 소구 기능 빠짐없이)

> 코드/SPEC 19종 대조로 세운 인벤토리. 홈페이지 소구에 쓸 것 중심.

**1) 통합 성과 이해**
- 자사몰 매출(Cafe24)·광고(메타·구글)·방문/유입(GA4)을 **한 화면**에. 월추이·상품별 매출·조회수·매출 비중·플랫폼별.
- 광고가 실제 매출로 이어졌는지 한눈에(광고↔매출 연결).

> 광고 만들기·운영 모듈 이름 = **애드캔버스(AdCanvas)** — 메타·구글 공통. 홈페이지에서 이 이름을 써도 됨.

**2) 애드캔버스 · 메타 광고 만들기·운영**
- **원클릭 광고**: 상품 URL 입력 → 이미지·문구를 골라 4스텝으로 게시.
- 직접 만들기(업로드·크롭·설정) + **광고 만들기 중 인스타그램 실시간 미리보기**(Feed/Reels).
- **동적/자동 카탈로그 광고**: 카페24 **28일/7일 판매 베스트**를 자동 세트로 묶어 카탈로그(다이나믹) 광고로. 하루 1회 상위 상품을 메타에 push → 카탈로그 제품 세트가 바뀜 → **잘 팔리는 상품이 광고에 자동 반영**. (CEO 확인 2026-07-07) ⚠카피 주의: 여기서 "자동"은 **상품 세트가 판매 데이터로 자동 갱신**된다는 뜻 — "AI가 알아서 광고를 만든다/집행한다"가 **아니다**(정직 가드레일 §G).
- 리타겟팅(DPA) 카탈로그 광고.
- 성과 4단계(계정→캠페인→광고세트→광고) + 예산·상태·스케줄 직접 조정.
- **집행 중인 광고 소재 실시간 확인**(메타 API): 지금 돌고 있는 광고의 실제 소재를 본다 — 단일 이미지 광고는 문구까지 전체, 영상은 썸네일. (CEO 확인 반영 2026-07-07) ※내부(카피 아님): 캐러셀은 아직 미표시·영상은 재생 없이 썸네일만 — 카피는 "집행 중 소재 확인"까지, 세부 제약은 홈페이지에 안 씀.

**3) 애드캔버스 · 구글 광고 만들기·운영**
- 검색광고(RSA): 헤드라인·설명 에디터 + **광고 효력(Ad Strength) 실시간** + **AI 문구 추천** + 키워드/제외키워드 + 정책 검증.
- 간편 모드(Easy) · 실적 최대화(PMax) 생성.
- 성과 조회 + **최적화 점수**(광고 건강도).

**4) 시장 트렌드 · 경쟁 비교**
- 29CM·에이블리 **베스트 랭킹** — 카테고리별 + **급상승·신규 진입·순위 하락** 타입별 + 이번주 vs 지난주 순위 변동 + **우리 브랜드 자동 식별**.
- **경쟁 비교(29CM 전용)**: 경쟁사 브랜드 TOP20 상품 + 리뷰 + **잘나가는 상품 vs 우리 상품 매칭**(우리가 시장 어디쯤인지).
- **AI 이미지 벤치마크**: **우리 몰 베스트 상품 → AI가 특징(패션 키워드) 추출 → 시장(29CM·에이블리)에서 비슷하게 잘나가는 상품을 찾아줌**(소재·기획 참고).
- **검색량**: Google 검색 유입(검색어별 클릭·노출·순위) + **네이버 일간(우리 브랜드 추산)·월간(자사 vs 경쟁사) 검색량 비교**.
- 각 트렌드에 **AI 인사이트**(사람 말 해석) 사이드바(29CM·에이블리 둘 다).

**5) 월간 AI 리포트 (9개 항목)**
매출 / 유입 채널 / 구매 여정 퍼널 / 베스트 상품 / 29CM 시장 트렌드 / 광고 소재 성과 랭킹 / 시장 vs 자사몰 비교 / **다음 달 목표·전망** / **전략 액션 플랜** — 숫자를 AI가 사람 말로 풀어서.

**6) AI 도우미(챗봇)**
매출·광고·용어를 물어보면 **AI가 어려운 숫자를 쉬운 말로 풀어 답하고 어디서 보는지 안내**하며, **광고 켜기/끄기·예산도 말로 바꿀 수 있는** 도우미. (수위: 설명·안내 + 광고 변경 명령(수동·본인계정). 예약·자동집행·AI 판단은 안 함.)

**7) 다店 관리**
여러 스토어/브랜드를 한 계정에서.

> ※ §1 요약에서 약하게 담겼던 소구 포인트(원클릭 광고·AI 문구 추천·AI 이미지 벤치마크·월간리포트 익월목표+액션플랜·최적화 점수·네이버 검색량)를 인벤토리로 끌어올렸음 — 랜딩에서 빠뜨리지 말 것.

## D. 기능 그리드 (카드: 헤드 + 한 줄)

## E. 가격 (UI 초안 · E0-1 그로스 신설 반영)

> 원칙: **광고비 %수수료 없음. 월 정액 + 1개월 무료.** 앵커 = "대행 수수료 대체".
> **E0-1 확정**: 스타터 9.9 ↔ 프로 39~49 사이 **4배 갭을 그로스 19.9만으로 메움**(업로드 2티어와 사다리 대칭). ⚠티어별 세부 기능 배분·가치 차이 명확화는 **E2-5(가격 카피, 사장님 승인)**에서 확정 — 아래 담김은 방향 뼈대일 뿐 지어내기 금지("10만 더 받고 기능 1개" 패턴이면 게이트② 반려).

| 티어 | 대상 | 월 정액 | 담김(방향 — E2-5 확정) |
|---|---|---|---|
| **무료체험** | 신규 | 1개월 무료 | 전 기능 |
| **스타터** | 1인 쇼핑몰 | 9.9만 | 스토어 1 · **연결 매체 제한(예: 2채널)** · 핵심 기능 |
| **그로스** ★신설 | 성장 초입 셀러 | 19.9만 | 스토어 1 · 매체 확장 · AI 챗봇·월간 리포트 상시 (프로와 가치 차이 E2-5 명확화) |
| **프로** | 성장 셀러 | 39만~49만 | 전 매체 · 월간 리포트 자동 · 보존 연장 |
| **비즈니스** | 다店·대형 | 문의(맞춤) | 다스토어 · 전담 지원(연간) |

- **셀링 한 줄**: "광고비가 늘어도 요금은 그대로. 대행 수수료 대신 정액."
- (내부 참고, 카피 아님) 스타터는 채널/계정 상한을 **반드시 명시**해야 저가가 방어됨. 비즈니스는 순수 월정액 셀프서브가 아니라 맞춤/연간으로 포지션. **그로스↔프로 가치 차이가 명확해야 함**(E0-1 ② 단서).
