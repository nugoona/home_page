# AdCanvas Meta - 기술/기능 명세서

> **문서 버전:** v1.0
> **최종 수정:** 2026-02-08
> **대상:** Meta(Instagram/Facebook) 광고 운영 관리자

---

## 1. 제품 개요

AdCanvas Meta는 **Meta(Instagram/Facebook) 광고를 웹 UI에서 직접 생성, 관리, 분석**할 수 있는 통합 광고 관리 도구입니다. 이미지 단일 광고부터 카탈로그(다이나믹) 광고, 원클릭 AI 광고까지 지원하며, 광고 생성 → 성과 분석 → 최적화의 전체 라이프사이클을 하나의 인터페이스에서 처리합니다.

### 핵심 가치

| 가치 | 설명 |
|------|------|
| **원클릭 AI 광고** | 상품 URL만 입력하면 이미지 추출 → 크롭 → AI 문구 생성 → 즉시 게시 |
| **5단계 카탈로그 광고** | 세트 선택 → 타겟팅 → 소재 → 예산 → 게시 단계별 가이드 |
| **실시간 미리보기** | Instagram 피드/스토리 형태로 광고 실시간 미리보기 |
| **통합 성과 관리** | 캠페인/세트/광고 레벨 성과 분석 + ON/OFF + 예산 조정 |
| **멀티 소재 지원** | 단일 이미지, 캐러셀, 카탈로그, 동영상 광고 생성 |

## 2. 페이지 구조 (전체 플로우)

```
/adcanvas/select-platform              ← 플랫폼 선택 (Meta / Google)
    │
    ▼
/adcanvas/select-account-meta          ← Meta 광고 계정 선택
    │
    ▼
/adcanvas_meta?account_id=XXX          ← AdCanvas Meta 메인 페이지
    │
    ├──→ 원클릭 광고: /adcanvas_meta/oneclick
    │       (Step 1: URL → Step 2: 이미지 선택 → Step 3: 크롭 → Step 4: 게시)
    │
    ├──→ 직접 만들기 (단일 이미지):
    │       /adcanvas_meta/create → /crop → /adcreate → /publish
    │
    ├──→ 카탈로그 광고:
    │       /catalog/step1 → /step2 → /step3 → /step4
    │
    ├──→ 광고 관리: /adcanvas_meta/manage
    │
    └──→ 성과 분석: /adcanvas_meta/performance
```

## 3. 플랫폼 선택 페이지

**URL**: `/adcanvas/select-platform`
**템플릿**: `adcanvas_platform_select.html`

### UI 구성

- **서브타이틀**: "플랫폼 선택"

  - **Google Ads**: 흰색 배경, Google Ads 4색 로고, "검색 & 디스플레이 광고 관리"
- **다크 테마**: `#0a0a0a` 배경, 그레인 텍스처 오버레이

|------|------|----------|

## 6. 원클릭 광고 (One-Click Ad)

**URL**: `/adcanvas_meta/oneclick?account_id=XXX`
**템플릿**: `admake_oneclick.html`

### 6.1 개요

상품 URL 하나만 입력하면 **이미지 추출 → 선택 → 크롭 → AI 문구 생성 → 즉시 게시**까지 한번에 처리되는 자동화 플로우입니다.

### 6.2 Step 1 — URL 입력 / 직접 업로드

| 기능 | 설명 |
|------|------|
| **URL 입력** | 상품 상세 페이지 URL 입력 |
| **URL 검증** | Cafe24, MakeShop, GodoMall, Imweb 상세페이지 패턴 검증 |
| **차단 패턴** | 카테고리, 메인, 이벤트, 기획전 페이지 자동 차단 |
| **이미지 추출** | Cloud Run 이미지 추출기 API로 상품 이미지 자동 수집 |
| **직접 업로드** | 드래그 앤 드롭 또는 파일 선택으로 이미지 업로드 |

**URL 검증 로직 (우선순위 기반):**
1. PRODUCT_URL_PATTERNS 먼저 체크 (상품 페이지면 허용)
2. BLOCKED_URL_PATTERNS으로 차단 (카테고리/메인/이벤트)
3. 패턴 매칭 없으면 허용 (기본 허용)

**지원 쇼핑몰 플랫폼:**

| 플랫폼 | 상품 URL 패턴 |
|--------|--------------|
| Cafe24 | `/product/상품명/번호/category/` |
| MakeShop | `/shop/shopdetail.html?branduid=` |
| GodoMall | `/goods/goods_view.php?goodsNo=` |
| Imweb | `/products/상품명` 또는 `/product/상품명` |

### 6.3 Step 2 — 이미지 선택

| 기능 | 설명 |
|------|------|
| **3열 그리드** | 추출된 이미지를 3열 그리드로 표시 |
| **단일 선택** | 클릭 시 보라색 테두리 + 체크마크 |
| **이미지 정보** | width x height 표시 |
| **직접 업로드 스킵** | 직접 업로드 시 바로 Step 3으로 이동 |

### 6.4 Step 3 — 이미지 크롭

| 기능 | 설명 |
|------|------|
| **캔버스 크롭** | HTML5 Canvas 기반 실시간 크롭 |
| **비율 선택** | 4:5 (기본, 인스타 피드 최적) / 1:1 / 9:16 |
| **마우스 드래그** | 크롭 영역 이동 |
| **스크롤 줌** | 마우스 휠로 확대/축소 |
| **터치 지원** | 모바일 핀치 줌 + 드래그 |

### 6.5 Step 4 — 미리보기 & 게시

#### 좌측: Instagram 피드 미리보기

| 요소 | 설명 |
|------|------|
| **프로필 영역** | 계정 아이콘 + 계정명 + "Sponsored" 라벨 |
| **크롭 이미지** | 선택한 비율로 크롭된 이미지 표시 |
| **CTA 버튼** | "더 알아보기" (Learn More) |
| **반응 아이콘** | 좋아요, 댓글, 공유, 저장 |
| **캡션** | 주요문구 실시간 미리보기 |
| **실시간 반영** | 텍스트 수정 시 미리보기 즉시 갱신 |

#### 우측: 설정 패널

**광고 이름** (자동 생성):
- 형식: `[YYYYMMDD][단일][상품명(30자)]`
- 브랜드명 자동 제거 (BigQuery `company_brand_mapping` 테이블 활용)
- 한국어/영문 브랜드명 모두 제거

**텍스트 에셋 (아코디언 UI):**

| 필드 | 기본값 | AI 기능 |
|------|--------|---------|
| **주요문구** | AI 자동 생성 | Gemini 2.0 Flash 기반 Instagram 광고 카피 |
| **제목** | 상품명 (브랜드명 제거) | 칩 선택 UI (헤드라인/가격 조합) |
| **설명** | 업체 영문명 | 칩 선택 UI (설명/가격 조합) |

**AI 주요문구 생성 사양:**

| 항목 | 규격 |
|------|------|
| **구조** | 2줄 (후킹 라인 + 서브 라인) |
| **길이** | 80~120자 (Instagram 125자 잘림 기준) |
| **줄바꿈** | 정확히 1번 |
| **이모지** | 0~2개, 줄 끝 배치 |
| **계절 인식** | 현재 월 기준 계절 자동 판단 |
| **가격 추출** | JSON-LD + meta 태그에서 자동 추출 (₩ + 천단위 콤마) |
| **톤** | 자연스럽고 친근한 쇼핑 톤 |

**헤드라인/설명 칩 선택기:**
- 순서 기반 다중 선택 (클릭 순서가 조합 순서 결정)
- ①② 넘버링으로 선택 순서 표시
- 조합 결과 실시간 미리보기 반영

**광고 세트 선택 (칩 UI):**

| 옵션 | 설명 |
|------|------|
| **전환만** | 전환 캠페인 세트에만 게시 (기본) |
| **유입만** | 트래픽 캠페인 세트에만 게시 |
| **전환+유입** | 양쪽 세트에 동시 게시 |

세트가 없는 타입은 자동 비활성화됩니다.

**게시 플로우:**
1. `POST /dashboard/get_meta_token` → access_token 획득
2. 크롭 blob → `POST graph.facebook.com/v24.0/{act_id}/adimages` → image_hash
3. `POST /dashboard/oneclick/publish` → ad creative + ad 생성
4. Lottie 성공 애니메이션 + 결과 오버레이
5. Slack 알림 자동 발송

### 6.6 나가기 방지 시스템

| 트리거 | 동작 |
|--------|------|
| **햄버거 메뉴 링크** | 커스텀 모달 ("페이지를 나가시겠습니까?") |
| **F5 / Ctrl+R** | 키보드 이벤트 인터셉트 → 커스텀 모달 |
| **브라우저 뒤로가기** | popstate 이벤트 → 커스텀 모달 |
| **창 닫기** | beforeunload 차단 안함 (중복 방지) |

## 12. 핵심 백엔드 함수

### 12.1 `get_account_info(account_id, access_token)`

Meta 계정의 page_id, instagram_user_id, conv_adset_id, traffic_adset_id, UTM 파라미터, pixel_id를 조회합니다.

### 12.2 `create_ad_creative_internal()`

Meta Graph API로 광고 크리에이티브를 생성합니다:
- image_hash 기반 이미지 연결
- object_story_spec 구성 (link_data, page_id, instagram_actor_id)
- UTM 파라미터 자동 추가

### 12.3 `create_ad_internal()`

Meta Graph API로 실제 광고를 생성합니다:
- creative_id 연결
- adset_id 지정
- status 설정 (ACTIVE/PAUSED)
