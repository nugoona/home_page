# 트렌드 분석 - 기술/기능 명세서

> **문서 버전:** v1.0
> **최종 수정:** 2026-02-08
> **대상:** 이커머스 브랜드 마케터 / 상품 기획자

---

## 1. 제품 개요

트렌드 분석은 **29CM, Ably 등 외부 마켓플레이스의 베스트셀러 동향**을 추적하고, **AI 기반 이미지 벤치마크**, **네이버/구글 검색량 분석**을 제공하는 경쟁 분석 도구입니다. 매주 자동 수집된 데이터를 기반으로 급상승/신규진입/순위하락 상품을 식별하고, 자사 브랜드 상품이 포함된 경우 자동 강조합니다.

### 핵심 가치

| 가치 | 설명 |
|------|------|
| **경쟁 동향 파악** | 29CM, Ably 베스트 상품 주간 순위 변동 추적 |
| **급상승 감지** | 전주 대비 급상승/신규진입/하락 상품 자동 분류 |
| **자사 브랜드 추적** | 자사 상품이 베스트에 진입하면 자동 강조 표시 |
| **AI 이미지 벤치마크** | 자사 베스트 상품과 유사한 경쟁사 이미지 추천 |
| **검색 트렌드** | 네이버 브랜드 검색량 + 구글 검색 유입 분석 |
| **자동 수집** | 매주 월요일 자동 크롤링, 수동 개입 불필요 |

## 2. 페이지 구조

```
/trend/selection (또는 /m/trend/)          ← 플랫폼 선택
    │
    ├──→ /trend/29cm (또는 /m/trend/29cm)   ← 29CM 트렌드
    │
    ├──→ /trend/ably (또는 /m/trend/ably)   ← Ably 트렌드
    │
    ├──→ /trend/image-benchmark             ← AI 이미지 벤치마크 (Beta)
    │
    └──→ /trend/search-volume               ← 검색량 분석 (Beta)
```

PC(`/trend/*`)와 모바일(`/m/trend/*`) 모두 지원하며, 디바이스 감지로 자동 라우팅됩니다.

## 4. 29CM 트렌드

**URL**: `/trend/29cm?company_name=XXX` 또는 `/m/trend/29cm?company_name=XXX`
**템플릿**: `trend_29cm.html`

### 4.1 데이터 수집

| 항목 | 설명 |
|------|------|
| **수집 주기** | 매주 월요일 08:00 KST (Cloud Run Job) |
| **Cloud Run Job** | `ngn-29cm-best-job` (2Gi 메모리) |
| **수집 스크립트** | `tools/trend_29cm_snapshot.py` |
| **BigQuery 테이블** | `platform_29cm_best` |
| **수집 범위** | 카테고리별 베스트 100 상품 |

### 4.2 카테고리 탭 (Sticky)

**API**: `GET /m/trend/api/29cm/tabs`

상단 고정(sticky) 가로 스크롤 탭으로 카테고리를 전환합니다.

| UI 요소 | 설명 |
|---------|------|
| **탭 스타일** | 비활성=밝은 회색, 활성=검정 배경+흰색 텍스트 |
| **스크롤** | 가로 스크롤 + 스크롤 인디케이터(thumb) |
| **동적 로딩** | API에서 카테고리 목록 자동 조회 |
| **기본값** | "니트웨어" 카테고리 |

**카테고리 예시**: 니트웨어, 티셔츠, 팬츠, 아우터, 원피스, 스커트, 셔츠/블라우스, 가방 등

### 4.3 트렌드 유형 필터

4가지 필터 버튼으로 상품을 분류합니다:

| 필터 | 아이콘 | 색상 | 조건 |
|------|--------|------|------|
| **전체** | 그리드 | 검정 | 급상승 + 신규 + 하락 통합 |
| **급상승** | 불꽃 | 빨강 (#ef4444) | 전주 대비 순위 상승 |
| **신규진입** | 별 | 녹색 (#22c55e) | 전주 미진입 + 현재 순위 ≤ 20 |
| **순위하락** | 하향 화살표 | 파랑 (#3b82f6) | 전주 대비 순위 하락 |

### 4.4 순위 변동 계산

**API**: `POST /m/trend/api/29cm/data`

```
급상승 조건: previous_rank > current_rank (순위 숫자 감소 = 상승)
신규진입 조건: 전주 데이터 없음 AND current_rank ≤ 20
순위하락 조건: previous_rank < current_rank (순위 숫자 증가 = 하락)
```

### 4.5 상품 카드

| 요소 | 설명 |
|------|------|
| **이미지** | 88x88px 정방형 썸네일 (lazy loading) |
| **순위** | 대형 볼드 텍스트 |
| **변동 배지** | +N (빨강) / NEW (녹색) / ▼N (파랑) |
| **자사 배지** | "자사" 보라색 그라데이션 배지 (자사 브랜드 상품) |
| **브랜드명** | 12px 회색 텍스트 |
| **상품명** | 14px, 2줄 말줄임 |
| **가격** | 15px 볼드, ₩ + 천단위 콤마 |

### 4.6 자사 브랜드 식별

BigQuery `company_brand_mapping` 테이블에서 업체의 모든 브랜드 변형(한글/영문/약칭)을 조회하여, 상품의 `brand_name`과 매칭합니다.

```
예: piscess → ["파이시스", "PISCESS", "piscess", "Piscess"]
    → 이 중 하나라도 brand_name에 포함되면 "자사" 배지 표시
```

## 6. AI 이미지 벤치마크 (Beta)

**URL**: `/trend/image-benchmark?company_name=XXX`
**템플릿**: `trend_image_benchmark.html`

### 6.1 개요

자사몰 최근 7일 **베스트 판매 상품**을 기준으로, 29CM과 Ably에서 **유사한 트렌드 상품 이미지**를 AI가 자동 추천합니다. 상품 기획 및 촬영 레퍼런스로 활용할 수 있습니다.

### 6.2 플로우

```
자사몰 베스트 상품 조회 (7일)
    │
    ▼
AI 키워드 추출 (Gemini 2.0 Flash)
    │
    ▼
29CM/Ably에서 키워드 매칭 검색
    │
    ▼
관련도 점수 기반 이미지 그리드 표시
```

### 6.3 베스트 상품 탭

**API**: `GET /dashboard/image-benchmark/best-products?company=XXX`

| 기능 | 설명 |
|------|------|
| **데이터 소스** | Cafe24 최근 7일 판매량 기준 Top 5 |
| **탭 UI** | 가로 스크롤, 순위 번호 + 상품명 |
| **선택 스타일** | 활성=보라색 그라데이션 |
| **캐시** | `image_benchmark_best_products_cache` 테이블 (주간) |

### 6.4 AI 키워드 추출

**API**: `POST /dashboard/image-benchmark/extract-keywords`
**AI 엔진**: Google Gemini 2.0 Flash

상품명에서 5가지 카테고리의 키워드를 추출합니다:

| 카테고리 | 가중치 | 예시 |
|----------|--------|------|
| **Category** | 10점 | hoodie, cargo pants, blazer |
| **Design** | 8점 | shirring, frill, pleated |
| **Style** | 5점 | denim, vintage, fleece |
| **Fit** | 5점 | oversized, long sleeve, wide |
| **Pattern** | 1점 | stripe, floral, check |

**캐싱**: BigQuery `ai_keyword_cache` 테이블 (MD5 해시 기반)

### 6.5 키워드 검색 & 이미지 그리드

**API**: `POST /dashboard/image-benchmark/search-by-keywords`

| 기능 | 설명 |
|------|------|
| **검색 대상** | 29CM + Ably 최신 주간 베스트 상품 |
| **매칭 방식** | LIKE 연산자, 소문자 통일 |
| **스코어링** | 카테고리별 최대값 합산 (중복 방지) |
| **결과 수** | 최대 30개 |
| **정렬** | 관련도 점수 DESC → 순위 ASC |

### 6.6 이미지 그리드 UI

| 요소 | 설명 |
|------|------|
| **레이아웃** | Pinterest 스타일 2열 그리드 |
| **비율** | 3:4 (이미지 영역) |
| **순위 배지** | 좌상단, 보라색 그라데이션 (예: "상의 1위") |
| **점수 배지** | 우상단, 반투명 다크 (예: "5점") |
| **플랫폼 배지** | 좌하단, 29CM=다크 / Ably=마젠타 |
| **상품 정보** | 브랜드명 (보라색) + 상품명 (2줄 말줄임) |
| **좋아요 수** | 하트 아이콘 + 숫자 |

### 6.7 풀스크린 모달

이미지 클릭 시 풀스크린 모달이 열립니다:

| 요소 | 설명 |
|------|------|
| **배경** | `rgba(0,0,0,0.95)` 풀스크린 오버레이 |
| **이미지** | 최대 70vh 높이 |
| **브랜드명** | 보라색 소형 텍스트 |
| **상품명** | 18px 대형 텍스트 |
| **관련도 점수** | 점수 표시 (있는 경우) |
| **CTA** | "상품 페이지 열기" 보라색 그라데이션 버튼 |

## 7. 검색량 분석 (Beta)

**URL**: `/trend/search-volume?company_name=XXX`
**템플릿**: `trend_search_volume.html`

### 7.1 개요

**네이버 브랜드 검색량**과 **구글 Search Console** 데이터를 통합하여 브랜드 인지도와 검색 유입을 분석합니다.

### 7.2 Google Search Console 섹션

**API**: `GET /dashboard/search-console?company=XXX&limit=50&min_clicks=1`

| 기능 | 설명 |
|------|------|
| **기간** | 최근 28일 (자동) |
| **검색어 목록** | 노출수 기준 내림차순 |
| **초기 표시** | Top 10 쿼리 |
| **더보기** | 나머지 쿼리 확장 |

**검색어 카드 구성:**

| 요소 | 설명 |
|------|------|
| **순위 번호** | 1, 2, 3... 순차 넘버링 |
| **검색어** | 쿼리 텍스트 (말줄임) |
| **노출** | "노출 X" (노출 횟수) |
| **CTR** | "CTR X%" (클릭률) |
| **순위** | "순위 X" (평균 게재순위) |
| **클릭** | 대형 파란색 숫자 + "클릭" 라벨 |

### 7.3 네이버 일간 검색량 차트

**API**: `GET /dashboard/search-volume?company=XXX`

| 기능 | 설명 |
|------|------|
| **차트 타입** | Line chart (Chart.js) |
| **기간** | 30일 추이 |
| **데이터** | 추산 일간 검색량 |
| **라인 색상** | 녹색 (#22c55e) |
| **채움 영역** | 반투명 녹색 |
| **X축** | M/D 포맷 (예: "1/10") |
| **Y축** | K 접미사 (>1000) |

**통계 박스:**

| 지표 | 설명 |
|------|------|
| **월간 검색량** | 30일 합계 + "건" |
| **일평균** | 월간 / 30 + "건" |

### 7.4 네이버 월간 검색량 비교

동일 API 응답에서 경쟁사 브랜드 검색량과 비교합니다.

| 기능 | 설명 |
|------|------|
| **브랜드 목록** | 자사 + 경쟁사 검색량 내림차순 |
| **자사 브랜드** | 녹색 (#22c55e) 강조 + "자사" 배지 |
| **경쟁사** | 보라색 (#6366f1) |
| **분류** | PC / 모바일 분리 표시 |
| **수집일** | 수집 날짜 표시 |

**브랜드 카드 구성:**

| 요소 | 설명 |
|------|------|
| **순위** | 검색량 기준 자동 순위 |
| **색상 바** | 좌측 세로 바 (자사=녹색, 경쟁=보라색) |
| **브랜드명** | 이름 + 배지 |
| **PC/모바일** | "PC X / 모바일 Y" |
| **월간 검색량** | 대형 숫자 |
