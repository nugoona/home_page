# 콘텐츠 전략 플레이북 — 업종별 글감 가이드

> 로테이션 헌법(`docs/CONTENT-ROTATION-CONSTITUTION.md`)의 §2 원천 테스트를 실전 업종별로 풀어쓴 운영 가이드.
> 새 업체 온보딩 시 담당자·AI 모두 이 문서부터 읽는다.

---

## 1. 업종 분류 — 가장 먼저 할 일

모든 업종을 두 가지로 나눈다. **입력 흐름 전체가 달라지기 때문이다.**

| 모델 | 설명 | 해당 업종 |
|---|---|---|
| **모델 A (로테이션형)** | 시스템이 "오늘의 글감" 제안 → 사장님이 맞는 사진 찍어 주면 글 생성 | 요식업 전반(음식점·카페·베이커리·주점·분식·떡집), 무미건조 공간형(스터디카페·PC방·노래방·당구장) |
| **모델 B (이벤트형)** | 사장님이 행사·결과물 사진 올리면 → 글 자동 생성 | 그 외 모든 자영업 |

**판별 기준 (원천 테스트):** 아래 4종 원천 중 하나라도 있으면 → 모델 B

| 원천 종류 | 예시 업종 |
|---|---|
| **지식** — 가르칠·설명할 전문 지식이 무한 | 병원·의원·한의원·클리닉, 학원·교습소, 세무·법무사, 헬스·필라테스·요가, 마사지·웰니스 |
| **손님별 결과물** — 손님마다 결과가 달라 후기·사진이 쌓임 | 미용실·헤어, 네일·속눈썹·반영구, 피부과·성형외과, 펜션·풀빌라·스튜디오·사진관 |
| **상품 회전** — 새 상품이 계속 들어옴 | 편의점·무인점·다이소형 소매 |
| **장소·매물 변화** — 다루는 장소가 매번 바뀜 | 부동산, 인테리어·시공·이사 |

## 2. 모델 A — 요식업·공간형 로테이션 전략

> 핵심: 매일 같은 메뉴를 판다 → 소재 도배 위험 최고 → **로테이션 엔진 필수.**

### 2-1. 글감 유형 6가지 (§8 유형 축)

| 유형 | 기호 | 특징 | 1년치 편수 가이드 |
|---|---|---|---|
| 상품 메인 | 🥩 | 메인 메뉴 직접 소개 | 메인 메뉴 수 × 2~3편 |
| 현장·일상 | 🔥 | 오늘의 준비·조리·매장 현장 | 가장 두껍게 (마르지 않음) |
| 전문가 안목 | 👁 | 가게만 아는 기준·원칙 | 소수 2~3편만 (알맹이 고정) |
| 시즌·날씨 | ☁ | **진짜 계절 한정 메뉴만** | 해당 메뉴 없으면 0편 |
| (요식업 사용 안 함) | 🙋 | ~~손님 상황~~ | 0 — 손님 후기 시점 위반 |
| 새 소식 | ℹ | 신메뉴·임시 휴무 등 진짜 새 소식 | 없으면 0편 |

### 2-2. 업종별 공통 규칙

모든 모델 A 업종에 동일하게 적용:

1. **화자 = 가게 본인.** 손님·방문객·체험단 위장 절대 금지.
2. **도입부 인사말 금지.** "안녕하세요 OOO입니다" → 첫 문장부터 현장·메뉴·상황으로.
3. **강점 나열 금지.** 글마다 모든 강점을 열거하면 전 편이 같아 보임 → 해당 글에 필요한 1~2개만.
4. **가짜 계절 메뉴 금지.** 사철 파는 메뉴를 "여름 OO / 겨울 OO"로 쪼개면 사실 왜곡.
5. **사이드는 주인공 금지.** 본문에 자연스럽게 녹이는 것만.

### 2-3. 업종별 차별화 포인트

#### 요식업 — 음식점·식당·고깃집
- 메뉴 분류가 핵심: 메인(검색 주인공)·준메인(분기 1~2회)·사이드(곁들임 언급만)
- 🔥 현장형이 가장 강력: 불 앞, 고기 굽는 장면, 만석, 마감 직전 → 매일 달라 마르지 않음
- 메뉴 단순한 가게(예: 갈비집)일수록 🔥를 두껍게 배치
- 실증: 진스리움(공릉 갈비집) 36항목+재방문 16편=52편 통과

#### 요식업 — 카페·베이커리·디저트
- 음료 메뉴 다양 → 기간 한정·시즌 메뉴가 실제로 있으면 ☁ 활용 가능
- 공간 인테리어·조명·분위기가 🔥 현장형 풍부
- 계절 음료가 진짜 한정이면 ☁로 세울 수 있음 (아메리카노 같은 사철 메뉴는 ☁ 금지)

#### 무미건조 공간형 — 스터디카페·PC방·노래방
- 공간·시설 자체가 상품 → 🥩=공간 주인공
- 🔥 현장형: 오픈 준비·청소 루틴·새 시설 세팅·정기 점검
- 고정정보(가격·시간)는 글감 아님 — 플레이스·온보딩 프로필에 넣기

## 3. 모델 B — 비로테이션 업종별 글 누적 노하우

> 핵심: 원천이 있으니 로테이션 엔진 없이도 글감이 나온다. 그 원천을 어떻게 꺼내느냐가 관건.

### 3-1. 지식 원천형 — 병원·한의원·클리닉·학원·헬스·웰니스

**글감이 나오는 방식:** "환자·수강생이 자주 하는 질문 → 전문가(원장·강사)가 답하는 형식"

**글감 발굴 공식:**
- 이번 달 진료에서 가장 자주 받은 질문 3개 → 편당 하나씩 전개
- 계절·환절기·시기 특화 증상/케어 (봄꽃가루→알레르기, 여름→열사병, 겨울→관절)
- "원장님 치료 철학" — 비수술 우선·자연치유 등 진료 방향을 글 한 편으로
- 많이들 오해하는 것 — 일반인이 잘못 알고 있는 상식 교정

**사진 가이드:** 진료실 내부·장비·자세 교정 시연·처방전(익명) → 사진 1장이 자연스럽게 나옴

**⚠️ 병원 주의:** 의료광고 사전심의 해당 여부 확인 필수. "치료 효과 보장" 표현 자동 차단. 대신 "이런 증상에 이런 접근을 합니다" 수준으로.

**실증 (연세강남정형외과):** 진료과목 3개 영역×증상 심화·계절·철학·지역 특화로 40편 생성. 리뷰성 누수 0.

---

### 3-2. 손님 결과물형 — 미용실·헤어·네일·속눈썹·펜션·스튜디오

**글감이 나오는 방식:** 손님마다 결과가 달라 → 오늘의 작업 = 새 글감

**글감 발굴 공식:**
- "오늘의 [헤어 스타일 / 네일 디자인 / 투숙 스타일]" — 작업 결과물을 바로 글로
- 이번 달 가장 많이 요청받은 스타일 → 트렌드 설명
- 시술/숙박 준비 과정 — 사장이 준비하는 뒷이야기
- 계절·기념일 특화 작업 — 봄 웨이브·성수기 프리미엄 객실 세팅

**사진 가이드:** 완성 결과물(before/after) → 사진 1장이 가장 자연스러운 업종

**펜션 주의:** "잠실에서 40분 거리" 같은 입지/거리 정보는 사진이 없어 컷. 시설·풍경·운영 루틴 중심으로.
- ✅ 통과: 프라이빗 스파 세팅·계절별 강변 풍경·바비큐 타이밍·청소 루틴·기념일 세팅
- ❌ 컷: 잠실에서 40분·드라이브 경로·운영 정책·이름 유래

---

### 3-3. 상품 회전형 — 편의점·무인점·소매

**글감이 나오는 방식:** 새 상품 입고 = 자동 글감

**글감 발굴 공식:**
- 이번 주 신상 입고 → 간단 소개
- 계절 한정 상품 → 입고 알림
- "이걸 같이 사면 좋아요" 조합 추천

---

### 3-4. 장소·매물형 — 부동산·인테리어·시공

**글감이 나오는 방식:** 완공된 현장 = 새 글감

**글감 발굴 공식:**
- 최근 완공 현장 소개 (면적·스타일·특이사항)
- 시공 전·후 비교
- "이런 요청이 요즘 많아요" 트렌드 관찰

## 4. 모든 업종 공통 — 절대 바뀌지 않는 규칙

| 규칙 | 내용 |
|---|---|
| **촬영 가이드 기준** | 글감 한 줄마다 "현장에서 자연스러운 사진 1장이 나오는가" 검문. 안 나오면 컷 |
| **시점 = 가게 본인** | 손님 후기·체험단 위장 금지. "방문해봤다/먹어봤다" 표현 금지 |
| **도입부 인사말 금지** | 첫 문장부터 현장·서비스·상황으로 진입 |
| **키워드 = 지역+업종** | 오프라인은 지역 키워드가 결정적. 메뉴·시술명은 태그로 |
| **사이드 강등** | 검색해서 오는 것만 게시글 주인공. 곁들이는 것은 본문 언급만 |
| **꾸준함 > 퀄리티** | 완벽한 1편보다 꾸준한 52편. 조금씩 달라도 OK |
