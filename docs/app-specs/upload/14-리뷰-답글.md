# SRS 14 — 리뷰 답글 (배민·쿠팡 / 구글 / 네이버 플레이스)

> 서비스맵 8·9·10 한 묶음. 마스터 = [SRS.md](../SRS.md). 공통 불변식(§2)을 상속한다.
> 근거: `docs/GUIDE-SERVICE-MAP.md`(§1의 8·9·10, §4 코드 위치), `docs/STATUS.md`(리뷰 답글 AI 초안),
> 코드 `worker/src/reviews/*` · `src/app/api/reviews/reply/route.ts` · `src/app/(mobile)/review-reply/*` · `src/lib/review-quota.ts` · `worker/src/triggers/review-reply-watcher.ts`.
> ⚠️ 이 앱의 두 번째 기둥(발행 다음). "발행"과 달리 **손님이 남긴 글**에 답한다.

## 1. 목적
손님이 남긴 리뷰에 **사장님 시점의 답글 초안**을 AI가 만들어 준다. 별점이 낮으면 진심 사과와 개선
약속, 높으면 감사와 재방문 청유로 결이 갈린다. 가게 운영에 바쁜 사장님이 리뷰 하나하나 답글을
고민하지 않아도 되게 한다. **앱이 대신 등록하지는 않는다** — 초안을 만들어 보여 주고, 사장님이 보고
다듬어 직접 올린다(약관 안전·오답 방지).

세 갈래가 "초안 만들기" 엔진을 공유한다.
- **8) 배민·쿠팡**(붙여넣기) — 사장님이 리뷰 글을 붙여넣으면 초안 생성. **지금 라이브.**
- **9) 구글**(자동수집) — 채널 연결 후 미답변 리뷰를 자동으로 모아 초안. **예정.**
- **10) 네이버 플레이스**(자동수집) — 연결 후 미답변 리뷰를 자동으로 모아 초안. **예정.**

## 2. 액터·트리거
- **액터**: 사장님(리뷰 붙여넣기·복사), 앱(초안 요청 큐잉·한도 판정), 워커(발행 엔진, 초안 생성), Claude(LLM).
- **트리거(갈래별)**:
  - **8) 붙여넣기(라이브)**: 사장님이 "리뷰 답글 도우미" 화면에서 플랫폼·별점(선택)·리뷰 본문을 넣고 "답글 초안 만들기"를 누름.
  - **9)·10) 자동수집(예정)**: 채널 연결 후 정해진 주기로 **미답변 리뷰**를 자동으로 모아 초안까지 만들어 "모아보기"에 쌓음. 외부 수집 경로가 열려야 동작(§6·§8).

## 3. 입력
- **리뷰 1건**(`ReviewInput`): 본문(`text`, 필수), 별점(`rating` 1~5, 없으면 생략), 플랫폼(`platform`: `baemin`·`coupangeats`·`naver-place`·`google`·`etc`), 작성자 이름(`authorName`, 있으면 답글에서 자연스럽게 부름).
- **테넌트 프로필**: 상호(`storeName`)·소개(`intro`)·톤(`defaultTone` 6종)·강점(`highlights`)·제외어(`excludeKeywords` scope:'all'). 프로필이 없어도 기본 톤(따뜻하게)으로 동작한다.
- **붙여넣기(8)**: 사장님이 리뷰 글을 그대로 복사해 넣음(화면 플랫폼 선택 = 배민·쿠팡·기타).
- **자동수집(9·10)**: 연결된 채널에서 워커가 긁어온 미답변 리뷰(본문·별점·작성자·리뷰 고유값). *외부 연동 후.*

## 4. 처리 규칙·불변식
초안 프롬프트 = **사장 시점 선언 + 별점 분기 + 톤 + 강점(선택) + 제외어 + JSON 출력 지시** 결정론 조립(`buildReplyPrompt`).

- **[상속 C-1] 사장님 시점·정형 인사 금지·과장 금지.** 답글도 반드시 가게 사장 본인 시점 — 손님·체험단·제3자인 척 금지(사기). "안녕하세요 OOO입니다" 같은 똑같은 인사로 시작하지 않고 바로 마음을 전한다. 한글 이탤릭·em dash 금지.
- **[상속 C-3] 제외어(scope:'all')는 답글에서도 안 쓴다.** 성인·불법 오염어를 포함한 업체 제외어가 답글 본문에 새지 않게 프롬프트에서 금지 지시.
- **[상속 C-5] 비활성/정지 = AI 비용 0.** 초안 요청도 계정 게이트 안. 정지·비활성이면 초안이 나가지 않는다.
- **[REV-A] 자동 등록 없음(약관 안전).** 앱은 **초안만** 만들어 보여 주고 복사만 돕는다. 손님 리뷰란에 앱이 직접 글을 올리지 않는다. 오답·약관 위반·자동 스팸 위험을 원천 차단. 화면에도 "앱이 직접 등록하진 않으니 안심하세요"를 명시.
- **[REV-B] 별점 분기.** 별점 3점 이하 = 변명·반박 금지, 먼저 진심 사과 + 개선 약속 한 가지(과한 보상·할인 약속 금지). 4점 이상 = 감사 + 좋았던 점 공감 + 재방문 청유. 별점 없음 = 리뷰 결을 읽어 어울리게(단정 금지).
- **[REV-C] 톤·길이·이모지.** 톤은 프로필 `defaultTone` 6종에 맞춘다. 길이 2~3문장으로 짧고 진심이 느껴지게. 이모지는 0~1개까지만.
- **[REV-D] 하루 호출 한도(테넌트별).** 무제한 Claude 호출(비용·악용)을 막기 위해 **테넌트당 하루 30건**(`REVIEW_DAILY_LIMIT`). 트랜잭션으로 usage를 읽어 판정·증가, 초과면 거부(HTTP 429). 한도 리셋 경계 = **한국(KST) 자정**(`date`가 바뀌면 카운트 리셋).
- **[REV-E] 중복 처리 금지 = 트랜잭션 claim.** 앱이 `workerJobs`(kind='review-reply')에 큐잉하면 워처가 `queued`→`in-progress`를 트랜잭션 CAS로 선점한다. 두 워처·재시작이 같은 잡을 집어도 정확히 한 번만 생성.
- **[REV-F] 조용히 실패하지 않는다.** 생성 실패 시 `reviewReplyResults`에 `error`를 담아 완료 표시(무음 아님) — 화면이 "다시 시도해 주세요"를 띄운다. 빈 리뷰·LLM 실패·형식 오류(reply 누락)는 재시도(2회) 후 정직히 실패로 표시.
- **[REV-G] 자동수집(9·10)도 초안까지만.** 미답변 리뷰를 자동으로 모아 초안을 붙여 놓되, 등록은 여전히 사장님 손. 자동수집이 열려도 [REV-A]는 그대로.

### 배선(발행과 같은 "잡 큐 + 결과 컬렉션" 패턴)
앱(Cloud Run)에는 claude CLI가 없어 초안을 직접 못 만든다. 그래서
`/api/reviews/reply` → `workerJobs`(kind='review-reply') 큐잉 → `review-reply-watcher` → `generateReviewReply`(claude CLI) → `reviewReplyResults/{resultId}` write → 앱이 `onSnapshot`으로 구독해 표시(place-prefill·voice-transcribe와 동일). 결과 doc에는 요청자 본인(`requestedByUid`)을 담아야 클라 구독 인가가 통과한다.

## 5. 출력·성공
- **8) 붙여넣기**: 화면에 "AI 답글 초안" 카드(2~3문장, 사장 시점) + "복사해서 배민/쿠팡에 붙여넣기" 버튼 + "초안이에요, 한 번 다듬고 등록해 주세요" 안내. 복사 성공 시 토스트.
- **9)·10) 자동수집**: "미답변 리뷰 모아보기" 목록에 리뷰별 초안이 달려, 사장님이 확인·복사(등록은 각 플랫폼에서).
- **성공 판정**: 붙여넣은 리뷰가 인사말 없이·사장님 시점으로·별점 결에 맞게 답해지고, 제외어가 안 섞이며, 복사 한 번으로 사장님이 바로 붙여넣을 수 있다.

## 6. 예외·경계
- **빈 리뷰**: 400("리뷰 내용을 입력해 주세요"). 워커 단에서도 빈 텍스트면 즉시 실패 표시.
- **하루 한도 초과**: 429 + "오늘 만들 수 있는 답글 수(30개)를 다 썼어요. 내일 다시 이용해 주세요."
- **LLM 타임아웃·형식 오류**: 재시도(2회) 후 실패. 화면은 시간 초과(구독 90초)면 "시간이 오래 걸려요, 다시 시도해 주세요."
- **로그인 만료·테넌트 없음**: 401/403. 화면은 "로그인이 필요해요."
- **영어 등 외국어 리뷰**: 지금은 한국어 답글로 나감(언어 감지 보강은 후보). 정직히 한계로 남김.
- **자동수집(9·10)의 외부 의존 — 정직 표시**:
  - **9) 구글**: 미답변 리뷰 자동수집은 **GBP(구글 비즈니스) Reviews API**가 열려야 가능하고, 그 선행이 **구글 비즈니스 앱 승인**(사장님·1~2주, SRS 10과 함께)이다. 승인 전에는 자동수집 불가 — 화면은 "곧 제공"만 정직히 보여 준다(가짜 목록 금지).
  - **10) 네이버 플레이스**: 미답변 리뷰 자동수집은 **플레이스 연결(CDP 세션) 기반**이고, 실 스마트플레이스 계정으로 수집 경로(선택자)를 확정해야 한다(SRS 08 플레이스 연결과 짝). 확정 전 자동수집 불가 — "곧 제공"만 보여 준다.
  - **오작동 금지**: 자동수집 백엔드가 없을 때 가짜 리뷰 목록을 채우지 않는다. 빈 상태 + "채널 연결 준비가 끝나면 여기서 바로 보여 드릴게요"만.

## 7. 수용 기준
- [ ] 리뷰를 붙여넣고 별점을 주면 사장님 시점 초안이 2~3문장으로 나오고, 인사말 없이 시작한다(실 LLM 스모크로 눈 확인).
- [ ] 별점 1~3점 리뷰엔 변명 없이 사과+개선 약속이, 4~5점엔 감사+재방문 청유가 담긴다.
- [ ] 업체 제외어(scope:'all')가 답글 본문에 절대 안 섞인다.
- [ ] 앱이 리뷰를 **자동 등록하지 않는다**(초안+복사만) — 화면에 안심 문구가 보인다.
- [ ] 같은 테넌트가 하루 30건을 넘기면 31번째는 429로 거부되고, 한국 자정 지나면 다시 된다.
- [ ] 같은 잡을 워커가 두 번 집어도 초안이 한 번만 생성된다(트랜잭션 claim).
- [ ] 생성 실패 시 무음이 아니라 화면에 "다시 시도해 주세요"가 뜬다.
- [ ] 구글·네이버 자동수집 화면은 백엔드 없을 때 가짜 목록 없이 "곧 제공" 빈 상태만 보인다.
- [ ] 검증은 ②에뮬레이터 통합(한도 트랜잭션·잡 claim은 단위로 못 잡음) + ③실 Claude 스모크(초안 품질 눈 확인)까지.
