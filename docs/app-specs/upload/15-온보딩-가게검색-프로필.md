# SRS 15 — 온보딩·가게검색·프로필

> 앱의 첫 관문. 마스터 = [SRS.md](../SRS.md). 공통 불변식(§2)을 상속한다.
> 근거: `docs/ONBOARDING.md`(단일 진실, file:line 포함), `docs/KEYWORD-TAGSET-RULES.md`,
> 크롤 표준 [[reference_crawl_standard_apollo]]·list-item 타입 [[reference_pcmap_listitem_types_by_industry]].
> ⚠️ 가게검색·자동채움·프로필저장·글감빌드 트리거를 건드리기 전 ONBOARDING.md를 먼저 읽는다.

## 1. 목적
사장님이 **가게 이름 한 칸만 입력**하면 시스템이 나머지를 다 채운다. 네이버 지도에서 가게를 찾아
상호·주소·전화·리뷰수·메뉴·영업시간·소개·대표키워드를 자동으로 긁어오고, 그걸로 업종·노출 키워드·톤·
썸네일까지 알아서 정한 뒤 "다 준비했어요"로 요약해 저장한다. 사장님이 하는 건 **이름 입력과 "맞아요" 탭
두 가지가 전부**. 앱을 처음 쓰는 사장님이 막히지 않고 채널 연결까지 도달하게 하는, 사장님이 특히 중요하게
꼽은 관문 기능.

## 2. 액터·트리거
- **액터**: 사장님(가게명 입력·후보 선택), 앱(검색 잡 큐잉·결과 구독), 로컬 워커(크롤), Claude(업종 분류·소개 작성).
- **트리거**: 로그인 후 프로필이 없으면(`needsProfile`) `/onboarding/profile`로 강제 진입(SRS 16과 연결).
  사장님이 가게명을 넣고 검색을 누르면 시작된다.
- **4단계 흐름**: `1/4 가게검색` → (`2/4 수동 폴백`) → `3/4 준비완료` → `4/4 채널연결`.

## 3. 입력
- **가게 이름 한 줄**(필수 입력의 전부). 중복 단어는 자동 정리(`dedupeSearchTokens`, "소들녘 서초 소들녘 서초"→"소들녘 서초").
- **후보 선택 탭**("이 중 사장님 가게가 있나요?"에서 하나 선택 = placeId).
- **동네 이름**(후보가 20개 초과·0건일 때만 추가로 받아 검색을 좁힌다).
- **수동 입력**(못 찾았을 때만): 업종 그리드 선택 → 지역.
- 시스템이 스스로 채우는 것: 네이버 플레이스 상세(상호·주소·전화·리뷰수·메뉴·영업시간·소개·대표키워드).

## 4. 처리 규칙·불변식
검색 = **로컬 워커의 순수 HTTP 크롤**. 자동 채움 = **파싱(메뉴·리뷰·소개) + Claude(업종·강점·소개 글)** 조립.

- **[상속 C-3] 노출 키워드 자동 생성·주입.** 크롤한 업종·지역·상호로 추천 키워드·태그세트를 자동으로 만든다.
  성인·불법 금칙어(`isProhibitedKeyword`)는 이 단계에서도 걸러진다.
- **[상속 C-5] 활성화 게이트.** 온보딩·정보 입력·검색은 무료지만, 추천 키워드가 유료 네이버 검색도구를 부르는
  경로(`/api/keywords/recommend`)는 `accountAllowsAiWork`로 막는다(정지·비활성이면 `not_activated`).
- **[ONB-A] 크롤은 로컬 워커에서만, 워커 죽으면 즉시 수동 안내.** Cloud Run 금지(네이버 IP 차단, 로컬은 1년 무차단
  실적). 큐잉 전 heartbeat로 워커 생존을 본다(임계 120초). 죽었으면 무한 로딩 대신 바로 수동 입력으로 보낸다.
- **[ONB-B] 표준 크롤 = 순수 HTTP + `__APOLLO_STATE__` 파싱, Playwright·브라우저 자동화 금지.**
  `pcmap.place.naver.com/place/list?query=` GET → HTML의 `window.__APOLLO_STATE__` JSON 파싱.
- **[ONB-C] 후보는 목록 선택형, 단일 1등 카드 금지.** 후보를 여러 개 보여주고 사장님이 고르게 한다.
  1등만 자동 확정하면 동명·유사 상호를 오매칭해 엉뚱한 가게 정보로 온보딩되는 사고가 난다.
- **[ONB-D] 검색 0건 ≠ 가게 없음.** 429·5xx·타임아웃이면 `rateLimited=true`로 표식하고 "잠시 후 다시"로 안내
  (직접 입력으로 떨어뜨리지 말 것). 정상 200으로 빈 결과여야 진짜 0건이다. 업종별 list-item 타입이 다르므로
  (일반·숙박·병원) 한 타입만 보면 그 업종이 통째로 0건이 된다 — 세 타입 + 구조적 폴백으로 판정.
- **[ONB-E] 느린 LLM을 기다리지 말고 중간 머지.** 크롤 결과(메뉴·동)를 먼저 올리고, 업종은 분류가 끝나는 즉시
  따로 먼저 올린다(느린 소개 글쓰기 ~50초를 안 기다림). 클라 상세 타임아웃 120초. 이걸 줄이면 정상 완료를
  잘라 수동 업종 화면으로 새는 사고(또바기쌈밥)가 재발한다.
- **[ONB-F] 프로필 저장이 미발행 글 본문을 자동 재작성하지 않는다.** 규칙(키워드·제외어·지시사항)이 바뀌면
  안 나간 글엔 "규칙 갱신 필요" 표식만 달고 본문은 안 건드린다(발행 직전 게이트가 현행 기준 적용). 저장 한 번에
  수십 개 본문이 우르르 재작성되는 폭주를 막는다. 설정은 새 글부터 적용.
- **[ONB-G] 키워드 빌더는 앱·워커 미러 동기.** `src/lib/keyword-builder.ts`와 `worker/src/content/keyword-builder.ts`를
  한쪽만 고치면 화면 추천과 실제 발행 키워드가 어긋난다. 항상 같이 고친다.

## 5. 출력·성공
- **후보 목록**: 가게명 검색으로 후보를 보여주고 사장님이 자기 가게를 고른다.
- **자동 채움 요약(3/4 준비완료)**: 상호·업종·지역·톤·메뉴·소개·노출 키워드·태그·썸네일 설정이 다 채워진
  "다 준비했어요" 화면. 사장님은 "좋아요, 시작하기"만 누르면 된다.
- **프로필 저장**: `/api/profile`가 가게 정보 + 자동 생성 키워드·태그·썸네일 설정을 저장한다.
- **채널 연결(4/4)**: 네이버·인스타·페북 연결로 이어진다. 업종이 글감 제안형(모델A)이면 1년치 글감을 미리
  만들고(`/rotation/building`), 행사형(모델B: 웰니스·소매·이커머스)이면 글감 카드 없이 바로 홈으로.
- **성공 판정**: 사장님 입력이 "이름 + 맞아요 탭"만으로 프로필이 완성되고 채널 연결까지 도달.

## 6. 예외·경계
- **못 찾음·아니에요·타임아웃**: 홈페이지 웹 폴백(멀티소스 리서치)으로 넘어간다. 리서치 결과의 제목에는
  상호가 반드시 들어가야 채택(엉뚱한 페이지 오채택 방지). 그래도 없으면 수동 입력(업종 그리드 → 지역).
- **후보 20개 초과**: "동네로 좁히기" 프롬프트(상호 + 동네 재검색).
- **rate-limit 0건**: "네이버가 잠깐 응답을 못 했어요" + 다시 찾기(직접 입력으로 추락 금지).
- **워커 꺼짐**: 큐잉 안 하고 즉시 수동 입력 안내(무한 로딩 방지).
- **상세 크롤 지연(≈90초까지 정상)**: 120초 타임아웃 안에서 대기, 넘으면 이미 도착한 중간 업종을 사용.
- **부분 실패**: 소개 글쓰기가 늦거나 실패해도 크롤한 메뉴·업종으로 진행할 수 있게 중간 결과를 먼저 올린다.

## 7. 수용 기준
- [ ] 가게명 한 줄만 넣으면 후보 목록이 뜨고, 하나 고르면 상호·주소·전화·리뷰수·메뉴·소개·업종·키워드가 자동으로 채워진다.
- [ ] 후보는 여러 개 목록으로 보여주고 1등을 자동 확정하지 않는다(오매칭 방지).
- [ ] 크롤은 로컬 워커에서 순수 HTTP로만 돌고, 워커가 죽으면 무한 로딩 없이 즉시 수동 입력으로 안내한다.
- [ ] 연속 호출로 0건(rate-limit)이 나와도 "없는 가게"로 단정하지 않고 "잠시 후 다시"로 안내한다.
- [ ] 상세가 ~90초 걸려도 120초 안에 정상 완료되고, 늦으면 이미 도착한 중간 업종으로 진행한다(수동 업종 화면으로 안 샘).
- [ ] 프로필을 저장해도 이미 만든 미발행 글 본문이 재작성되지 않는다(표식만).
- [ ] 못 찾으면 웹 폴백(제목에 상호 필수) → 그래도 없으면 수동 입력(업종 그리드 → 지역)으로 이어진다.
- [ ] 검증은 ②실워커 + 실제 네이버 스모크 필수(rate-limit·타임아웃·업종별 list-item 타입은 단위로 못 잡음),
      글감 빌드 큐잉은 ④풀저니(검색→선택→준비완료→채널→building 도달).
