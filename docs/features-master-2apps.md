## A. 업로드 앱 — "누구나 컨텐츠" (노출)

| 영역 | 기능 |
|---|---|
| 시작 | 상호명 자동 프리필(메뉴·업종·지역·키워드 네이버 크롤) · 1년치 글감 자동 제안(모델A 업종, 주1회) |
| 입력 | 사진+메모 · 음성 업로드 · 사진 Q&A |
| 작성 | AI 글(업종별 톤·본인 시점) · "말로" 수정 · 직접 편집 · 썸네일 자동 생성+칸 편집 |
| 발행 | 다채널 fan-out(네이버 블로그·플레이스·인스타·페북·구글 비즈니스·유튜브 쇼츠) · 발행 스케줄(즉시/예약·빈도·하루 채널당 1건) |
| 노출 | 실검색량 키워드 최적화 · 페이지 순위 추적 · 월간 노출 리포트 · **노출 소식 자동 반영**(★킬러, 아래) |
| 노출(지도) | ★ **네이버 플레이스·구글 비즈니스 지도 검색 노출** — 발행 시 플레이스 소식·구글에 함께 올라 **지도/플레이스 검색에 우리 가게가 보임**(6채널에 뭉개지 말 것 = 소상공인 별도 소구) |
| 부가 | 리뷰 답글 초안(배민·쿠팡) · 쇼츠·릴스 제작 · 여러 가게 한 계정 · 광고 세팅 지원(→대시보드) |

**카피 재료 — 노출 엔진 디테일** (`ngn_upload/docs/EXPOSURE.md`):
- 북극성 문장: **"검색 시 우리 가게가 보이냐"** — 등수 끌어올리기가 아니라 꾸준한 노출.
- **목표 키워드 엔진**: "고객이 검색하는 말 중 우리가 정답인 것"만 — ①가게 정체 카드(AI가 본질 정리) ②후보 3원 결합(의도±지역+결정론 조합+네이버 연관확장) ③정확도 4-티어 게이트 ④**실 검색량(30↑) 게이트** → 억지 키워드 없음. 지하철역·도보시간까지 파싱("미금역치과" 상권 키워드).
- **순위 추적 매일 07:40** — 네이버 블로그탭·플레이스·통합검색·구글 순위. 노출 소식이 다음 글감에 반영.
- **발행 규율**: 검토 후 즉시발행 기본 · 밀리면 빈도 분산 · **채널당 하루 1건 하드캡**(버스트 차단) → "매일 꾸준히, 스팸처럼 안 보이게".
- **글 생성 조합**: 중립 코어 + **업종 가이드 7종**(웹리서치 근거) + **톤 6종** + 업체 정보(연락처→CTA·금지어) → "우리 가게 말투로".
- ★ **노출 소식 자동 반영(킬러 소구, EXPOSURE.md §6)**: 앱이 **네이버 플레이스·블로그·인스타·당근·구글 5개 매체의 노출 동향을 매주 스스로(Claude 웹서치) 수집 → AI가 정직·노출관련만 판정(adopt) → 앞으로 발행 글에 자동 반영**. = 네이버·구글 노출 방식/트렌드가 바뀌어도 **앱이 알아서 최신으로 따라감**. 카피 방향: "노출 방식이 바뀌어도, 알아서 따라갑니다." ※기존 발행 글 재작성은 안 함(앞으로 생성 글에만). ※"댓글 반영"은 문서 미확인 — 사장님 확인 대기(현재는 '발행 글' 반영까지 확실).
- ★ **지도 검색 노출**: 발행이 네이버 플레이스 소식·구글 비즈니스에도 올라 **네이버 지도·플레이스·구글 지도 검색에 가게가 보임**. "블로그만이 아니라 지도에서도 찾게" — 소상공인 킬러 소구(6채널 목록에 뭉개지 말 것).

## B. 대시보드 앱 — "NGN 대시보드" (광고)
> 페이블 코드 검증으로 스케줄·엔진·빠진 기능까지 확정.

**1) 통합 성과 이해**
매출(카페24: sales·items·orders·product_catalog·refund) + 광고(메타·구글) + 방문(GA4: traffic·viewitem)을 **한 화면**, 광고↔매출 연결. `dashboard/app.py`

**2) 메타 애드캔버스**
- **원클릭 광고** · 직접 만들기 · 인스타 실시간 미리보기(Feed/Reels)
- **동적/자동 카탈로그**(`dynamic_Ads_meta.py`): 모든 업체에 **"[자동세트] 최근28일 베스트 60"·"최근7일 베스트 20"** 자동 생성·갱신. **매일 17:00**(scheduler) 카페24 판매 데이터→상품번호 추출→Meta product_set 필터 교체. **AI 아님(판매 실적 기반 결정론)**. → "어제 잘 팔린 상품이 오늘 광고 세트에 자동 반영."
- DPA 리타겟팅 카탈로그
- **성과 4단계 드릴다운**(`admake_performance_service.py`): 오늘 요약→캠페인 타입별(전환/유입/카탈로그)→세트별 광고→카탈로그 상품까지, 각 단계에서 **ON/OFF·예산·종료일 변경**
- **집행 중 소재 실시간 확인**(`meta_ads_preview.py`): 지금 돌고 있는 광고 실제 소재 — **단일 이미지·영상까지**(원본/재생 소스+고화질 썸네일). ※**캐러셀은 카피 제외** — 메타 API가 캐러셀 미리보기를 제공하지 않음(플랫폼 한계, 우리 앱 미완 아님). 코드가 배열을 반환해도 실제 미리보기 불가.

**3) 구글 애드캔버스** (`google_ads_api/*`)
검색광고(RSA, rsa_creator)+Ad Strength 실시간+AI 문구 추천 · PMax(pmax_creator) · 간편 모드 · 키워드/제외 · 최적화 점수 · 자산 관리(asset_handler) · 캠페인 관리(campaign_manager) · 성과(insights_handler·aggregator)

**4) 트렌드·경쟁비교**
- **29CM·에이블리 랭킹**(`trend_29cm/ably_service.py`): 급상승·신규 진입·순위 하락 3종 + 이번주 vs 지난주 + **자사 브랜드 자동 식별**. 수집 = **매주 월 아침** 크롤→GCS 스냅샷.
- **경쟁비교**(`compare_29cm_service.py`): 29CM 검색·리뷰 API 직접 호출→경쟁사 상품·리뷰→우리 상품 매칭. **매일 08:00**.
- **AI 이미지 벤치마크**(`data_handler.py` 4 API): 우리 몰 최근 7일 베스트 → **Vertex AI가 이미지 특징 키워드 추출** → **Brave Search로 시장 유사상품 검색**.
- **검색량**: 네이버(일간 06:00·주간 07:00)+구글 검색어별.
- **AI 인사이트 사이드바**: **매주 월 09:00** Claude가 업체별 주간 트렌드 인사이트 작성.

**5) 월간 AI 리포트 (9항목, 코드 1:1 확정)** (`report_api_handler.py`)
**매월 1일 06:00** BQ 스냅샷 → **16:00 Claude가 섹션 1~9 작성**: ①매출(전월비+일별) ②유입(GA4) ③퍼널 ④베스트상품 TOP10 ⑤29CM 시장트렌드 ⑥광고 소재 성과 ⑦시장 vs 자사 ⑧**다음달 목표(예측 포함)** ⑨**전략 액션플랜**. 숫자를 사람 말로.

**6) AI 챗봇** (`chat_rag_v5.py`·`docs/ctx/chatbot/`)

- **도움말 자유입력**: "매출·광고·트렌드 무엇이든" 자유 텍스트 → 라우팅→근거 수집→답변 (마케팅 노하우 578줄·52 Q&A 기반)
