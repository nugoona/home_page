## ★ 전역 금지표현 (오염 방지 — 최우선, 카피 쓸 때마다 대조)

이번 오염(목업의 "검색 1위·상단 노출·사진 한 장")이 여기서 걸러진다. **모든 기능의 원본 스펙이 아래를 명시적으로 못 박고 있다.**

- **순위·노출 보장 금지** — "검색 1위 / 상위노출 / 1페이지(노출) 보장 / 상단 고정". 우리는 글·광고를 **만들고 발행·측정**할 뿐, 검색/게재 순위를 보장하지 않는다(네이버·구글 정책·경매상 보장 불가).
- **성과 보장 금지** — "매출 상승 / ROAS 향상 / 전환·조회수·구독자·평점 상승 보장", "클릭 한 번으로 매출 몇 배".
- **우월 과장 금지** — "최저가 / 업계 1위 / 국내 유일".
- **북극성(콘텐츠 노출)** = "검색하면 **우리 가게가 보이느냐**(꾸준한 노출)"이지 등수 끌어올리기가 아니다. 알림도 **하락 경고만** 있고 "등수 달성" 개념이 없다(근거: EXPOSURE §4).
- **✅ 예외(정상 — 금지 아님)**: "29CM·에이블리 경쟁사 상품 **랭킹 조회**", 광고 성과 "**지출 순 정렬**", 검색량 "브랜드 비교 순위" 등 **데이터 조회·표시의 '순위'는 정상**. 남의 공개 순위를 보여주는 것이지, 우리 것을 올려준다는 보장이 아니기 때문.
- **AI 엔진** 언급 시 항상 'Claude'(원본 스펙에 Gemini/Vertex로 적힌 곳도 랜딩은 Claude로 통일). 단 **화면 카피에서는 "AI"로 풀어 씀**(타깃이 Claude를 모름 — 사장님 확정 2026-07-11).
- **★ 제품명 공식 표기 = "누구나 콘텐츠"** (사장님 확정 2026-07-11 — '콘'텐츠). 이 문서·옛 문서들의 "누구나 컨텐츠" 표기는 **전부 옛 표기**이니 화면·카피에 쓰지 말 것. 짝 = "NGN 대시보드". Nav·화면 라벨은 기능명이 아니라 **이 제품명**으로.

## ★ 채널별 사진/이미지 수 (사장님 반복 지적 — 절대 혼동 금지)

| 채널 | 필요 매수 | 근거 |
|---|---|---|
| **블로그(콘텐츠 발행)** | **유효 사진 4장 필수**(서로 다른 장면) | 발행 게이트 MIN_PHOTOS=4 (근거: SRS·OVERVIEW §5) |
| 네이버 플레이스 소식 | 이미지 1장 | CHANNELS(블로그 발행 성공 시 부가) |
| 광고(메타 원클릭·애드캔버스) | 이미지 1장(단일 선택) | SPEC_META_ONECLICK STEP2 |

> ⛔ **"사진 한 장이면 블로그"는 틀림 — 블로그는 유효 4장(서로 다른 장면).** 비슷한 사진 4장은 발행 보류되니 "4장만 찍으면 끝"도 아님. "이미지 한 장"은 **광고·플레이스 소식**에만.
> - ⚠️ **재오염 주의(2026-07-10 발견)**: 원본 스펙 `docs/app-specs/upload/SRS.md:19`의 한 줄 요약("사진 한 장 + 메모만 올리면…")은 **부정확한 마케팅 축약**이며, **같은 파일의 발행 게이트(MIN_PHOTOS=4)가 정본**이다. 원본 사본이라 그대로 두었으니, 그 줄을 카피 재료로 인용하지 말 것.
> - **두 층위 구분(혼동 금지)**: ①**발행 게이트** = 유효 4장(중복 앵글·식별불가 제외, MIN_PHOTOS=4, 근거 SRS·OVERVIEW §5) ②**생성 단계 본문 이미지 선별** = 뚜렷이 다른 이미지 3장 미만이면 블로그는 정당 실패·인스타는 단일 카드 폴백(근거 GENERATION §4). "3장이냐 4장이냐"로 헷갈리지 말 것.

# A. 콘텐츠 앱 — "누구나 컨텐츠" (검색 노출)

## A1. 사진 올리면 채널마다 글이 완성
- **한 줄**: 매장 사진을 올리면 연결해 둔 채널(네이버 블로그·인스타·페이스북)마다 그 채널에 맞는 글이 각각 자동 완성.
- **프로세스**: 사진(+행사·글감 메모) → ①중복 사진 걸러냄(dHash) ②켜진 채널 확인해 글 종류 결정 ③채널별 별도 글 생성 ④Claude가 본문·이미지·썸네일까지 작성 → 채널별 완성 글이 **검토 대기**로 도착.
- **핵심 사실**: 업로드 1건 = 켜진 채널 수만큼 글로 갈라짐(팬아웃) / 채널 글은 같은 사진·답변 공유 / 페이스북 글은 인스타 글 재사용 (근거: GENERATION §1·§2·§5).
- **⛔ 금지**: "무제한/무한 자동 생성"(켜둔 채널 수만큼만). 순위 보장 일체.
- **★ 소구 재료(원본 발췌 2026-07-11)**: 본질 = "업로드 1건은 **켜진 채널 수만큼 형제 글**로 갈라지고, 각 채널이 별도로 작성"(GENERATION.md:47). 실물 흐름 = 업로드 → (필요시 사진 질문, **질문 0개여도 정상 진행** :52) → 채널별 작성 → 검토대기. 채널별 차이 = 블로그(본문+키워드 제목)·인스타(카루셀, 커버=행사명 우선)·페북(인스타 완성본 재사용 또는 자체). 정직 = "실패는 조용히 죽지 말고 알린다"(:113). ⛔내부 용어(워처·CAS·dHash) 노출 금지.

## A2. 사진을 읽고 필요한 것만 물어봐 채움
- **한 줄**: 올린 사진을 업종 기준으로 분석해 글에 꼭 필요한 질문만 던지고, 사장님 답을 글에 반영.
- **프로세스**: 사진 → ①업종별 가치 기준으로 분류(Claude 1회) ②필요한 질문을 검토화면에 띄움 ③답 저장 → 모든 채널 글에 동시 반영해 작성.
- **핵심 사실**: 질문 0개여도 정상 생성(애매하면 사진 그대로 소재로) / 답은 한 번 저장하면 전 채널 반영 (근거: GENERATION §5·§6-c).
- **⛔ 금지**: "질문 없이도 알아서 완벽하게"(질문·답이 깊이를 만듦).

## A3. 업종에 맞는 오늘의 글감 제안
- **한 줄**: 매일 같은 걸 파는 가게도 소재가 마르지 않게, 업종에 맞춰 오늘 쓸 글감 제안.
- **프로세스**: 업종 설정 → 로테이션형(요식·공간)은 상품/현장/전문가안목/시즌/새소식 유형 회전, 이벤트형은 올린 행사·결과물 사진에서 글감 추출 → 그날 글감 제안.
- **핵심 사실**: 요식업 실증 갈비집 52편(36+재방문16), 병원 정형외과 40편 소재 확보 / 지식형(병원·학원·웰니스)은 자주받는 질문을 전문가 답변 형식으로 (근거: GUIDE-CONTENT-PLAYBOOK §2·§3).
- **⛔ 금지**: 병원·의료는 "치료 효과 보장"(의료광고 심의 대상).
- **★ 소구 재료(원본 발췌 2026-07-11)**: 본질 = "매일 같은 메뉴를 판다 → 소재 도배 위험 최고 → **로테이션 엔진 필수**"(PLAYBOOK:30). **유형 6가지**(:32~41) = 🥩상품 메인(메뉴 수×2~3편) · 🔥현장·일상(**가장 두껍게 — 마르지 않음**) · 👁전문가 안목(2~3편만) · ☁시즌(진짜 계절 한정만, 없으면 0편) · ℹ새 소식(없으면 0편). 실증 = **진스리움(공릉 갈비집) 52편** · 연세강남정형외과 40편. 소구 문장 후보 = "완벽한 1편보다 꾸준한 52편"(:144). ⛔🙋 손님 시점 유형 노출 금지 · 방문객 위장 카피 금지.

## A4. 검색에 걸리는 제목·태그 자동 구성
- **한 줄**: 검색 키워드를 제목 앞쪽·태그에 배치해 네이버에서 잘 노출되도록 글을 구성.
- **프로세스**: 본문·업종·키워드 → 제목 앞 30자에 검색 키워드 배치 → 태그 10~15개 구성.
- **핵심 사실**: 제목 앞 30자 키워드 우선(기업명은 뒤로) / 제목에 노출 키워드 없을 때만 '제목만' 보강 1회(실패해도 발행 안 막음) (근거: blog-writing-guide, GENERATION §6-b).
- **⛔ 금지**: "상위노출/1페이지/검색 1위 보장" — SEO 구성일 뿐 순위 보장 아님.

## A5. 사장님 시점의 현장감 있는 글
- **한 줄**: 손님·체험단 흉내가 아니라 **가게 사장님 시점**으로, 인사말 없이 현장이 그려지는 글.
- **프로세스**: 사진·답변·글감 → 시점을 사장님 본인으로 고정 → 인사말 없이 첫 문장부터 현장 → 확인된 사실만 서술 → 도입부·어미·표현 매번 변주.
- **핵심 사실**: 손님·체험단 위장이 프롬프트 차원 금지 / "안녕하세요 OOO입니다" 도입부 금지 / 근거 없는 사실(효능·산지) 안 지어냄 / 도입부 9종·어미 믹스로 반복 방지 (근거: GENERATION §3-b, blog-writing-guide).
- **⛔ 금지**: "손님/체험단 후기 대신 써준다"(위장 후기 설계상 금지), "없는 내용도 지어내 채운다".

## A6. 폰에서 검토·승인·예약·수정요청 (사람 승인 후에만 발행)
- **한 줄**: AI가 마음대로 올리는 게 아니라, **모든 글이 사장님 승인 후에만** 나간다. 폰에서 검토해 승인·예약·수정요청·재시도·예약취소.
- **프로세스**: 생성된 글이 검토 대기 → 사장님이 승인(발행 예약)·수정요청·예약취소 → 수정요청 시 본문·발행 소스 재작성 후 다시 검토 대기.
- **핵심 사실**: 검토 전이 5종(승인·예약·수정요청·재시도·예약취소) (근거: REVIEW) / 수정요청이 핵심 원칙(사장님 시점·인사말 금지·거짓 금지)과 충돌하면 원칙 우선 — 의도는 살리되 거짓은 안 넣음 (근거: GENERATION §3-b·§7).
- **홈페이지 취급 (사장님 확정 2026-07-11)**: **홈페이지에는 넣지 않는다 — 앱 내 도움말 영역.** "승인 후 발행"은 당연 전제라 랜딩에서 소구하면 오히려 "무단 발행 우려"를 환기시킨다. 전용 시각화·기능 그리드 카드 **둘 다 안 만든다.** (⚠ 이전에 'A6=핵심 신뢰 축'이라 적었던 것 폐기 — 사장님 판정: 홈피 비노출.)

## A7. 음성으로 남기면 받아써서 정리
- **한 줄**: 매장에서 음성으로 남긴 메모를 받아쓰고 정리해 글감으로.
- **프로세스**: 녹음 업로드 → 받아쓰기 → Claude가 글감으로 정리 (근거: GENERATION §2).

## A8. 썸네일·이미지 글자 금칙어·대체어 설정
- **한 줄**: 이미지 위 글자에 넣지 말 단어·대체어를 정하면, 이후 글은 물론 아직 발행 안 된 글의 이미지도 자동으로 다시 만듦.
- **핵심 사실**: 저장 즉시 미발행 글(검토대기·예약)의 썸네일·커버 재렌더, 이미 발행된 글은 그대로 (근거: GENERATION §2).

## A9. 여러 채널 한 번에 자동 발행
- **한 줄**: 승인된 글을 네이버 블로그·플레이스, 인스타, 페이스북, 유튜브, 구글 비즈니스 프로필까지 각 채널에 맞춰 대신 게시.
- **프로세스**: 각 채널을 한 번 연결(**네이버=폰 QR 로그인, 셀프 불가·운영 지원 절차 포함**, 메타=OAuth, 구글=가게 선택) → 자격증명 암호화 보관 → 승인 시 각 채널 형태로 발행 → 블로그 성공 시 플레이스 소식·구글 비즈니스 부가 게시.
- **핵심 사실**: 지원 6채널(네이버 블로그·플레이스·인스타·페북·유튜브·구글 비즈니스) / 자격증명 AES 암호화 / 플레이스·구글은 블로그 성공 후 부가 / **네이버는 셀프 연결 불가(운영자 QR 필수)** (근거: CHANNELS §2·§3·불변식 F).
- **★ 지도 소구**: 발행이 플레이스 소식·구글 비즈니스에 올라 **네이버 지도·플레이스·구글 지도 검색에 가게가 보임** — 소상공인 킬러(6채널 목록에 뭉개지 말 것).
- **⛔ 금지**: 순위 보장, "연결만 하면 바로 다 올라간다"(연결 필요), 내부 크론·dry-run 용어.

  2. **미답변 리뷰 "자동 수집"(네이버 플레이스·구글만) = 아직 없음(예정).** 리뷰를 모아 초안을 달아 주는 기능이며 **등록은 여전히 사장님 몫**. 구글은 GBP(구글 비즈니스) Reviews API + 구글 비즈니스 앱 승인(1~2주) 선행, 네이버는 플레이스 연결(CDP) 수집 경로 확정 선행. 스펙도 "승인 전 자동수집 불가 — 화면은 '곧 제공'만, 가짜 목록 금지"(`14-리뷰-답글.md:16·17·61·62·78·79`).
  - ⛔ **홈페이지 노출 금지(사장님 지시)**: 자동 수집은 **구현된 뒤에** 카피·목업에 넣는다. "정본에 없으면 없는 것." (완성 전제 규칙은 *설계된 기능을 현재형으로 쓰라*는 뜻이지, **원본 스펙이 ⬜예정으로 표시한 미구현 기능을 있다고 쓰라는 뜻이 아니다.**)
  - 참고: **당근은 리뷰 답글 스펙에 없다**(붙여넣기 대상 = 배민·쿠팡·기타). 당근은 A14 노출 소식 엔진의 매체 5종 중 하나로만 등장.
- **★ 홈페이지 취급 (사장님 확정 2026-07-10)**: 리뷰 답글은 **코어 기능이 아니다.** 전용 시각화 섹션을 만들지 말고 **`/content` S9 기능 그리드의 카드 한 장**으로만 다룬다(영상 제작·말로 수정·썸네일·스케줄·여러 가게와 동급). 큰 목업에 힘을 쓰지 말 것.

- **한 줄**: 반응형 검색광고 헤드라인·설명문을 만들고 실시간 Ad Strength·키워드 연동·정책 검증까지 받아 게시.
- **핵심 사실**: 헤드라인 최대15(각30byte·위치핀)·설명문 최대4(각90byte) / 바이트 실시간(한글2·영문1) / Ad Strength 4단계(Poor~Excellent, 100점) / 광고그룹 키워드 포함 체크·미포함 AI 보충 / 정책 위반 자동 검출 / Easy Mode=URL만 넣으면 AI가 전부 생성 후 검토 (근거: SPEC_ADCANVAS_GOOGLE 4·5장).
- **⛔ 금지**: "Ad Strength Excellent=1위 보장"(구성 품질 지표), "1페이지 보장"(게재는 경매), Gemini→Claude.

## B12. 구글 PMax 캠페인 만들기
- **한 줄**: 텍스트·이미지·동영상·사이트링크·검색 테마까지 PMax 전 에셋을 한 화면에서 구성하고 Ad Strength로 점검해 게시.
- **핵심 사실**: 텍스트(헤드라인3~15·긴헤드라인1~5·설명문2~5·비즈니스명 필수) / 이미지(가로1.91:1·정방1:1·세로4:5·로고) / 유튜브 3비율 / 사이트링크 최대4·검색테마 최대25 / URL 입력 시 AI가 전 에셋 추천(없는 URL 추측 안 함) / Ad Strength 4단계 (근거: SPEC_ADCANVAS_GOOGLE 6·7장).
- **⛔ 금지**: "Excellent=매출/전환 보장", "PMax로 매출 몇 배", Gemini→Claude.

## B13. 메타 광고 사전 세팅 (게시 직전 최종)
- **한 줄**: 만든 광고를 내보내기 전 노출 방식·예산·기간을 한 화면에서 확정.
- **핵심 사실**: 노출 방식 2종(새 광고만/기존과 함께) / 세트당 광고 최대 50개(초과 시 오래된 순 삭제 대상 자동 산출) / 전환·유입 캠페인 예산(CBO/ABO) / 노출기간(종료 없음/지정) / 유입 복사 시 UTM 자동 (근거: SPEC_META_MANAGE).
- **⛔ 금지**: 성과·순위 보장(게시 전 세팅).

## B14. 광고 성과 분석·관리 (메타·구글)
- **한 줄**: 게시한 메타·구글 광고를 캠페인→세트/그룹→광고 3레벨로 분석하고 예산·ON/OFF·소재·제외키워드를 한곳에서 관리.
- **핵심 사실**: 메타 KPI 7종(지출·구매·ROAS·전환율·유입당비용·CTR·AOV)·기간4종·3탭(전환·트래픽·카탈로그)·오늘은 실시간·과거는 BQ·예산 최소 1,000원·CBO/ABO 자동감지 / 구글 KPI 7종(지출·전환·ROAS·클릭·CPC·CTR·노출)·타입5종·키워드 매치(확장·구문·정확)·검색어 '제외' 빠른추가(구문일치)·예산 프리셋(±1·5·10만)·PMax 에셋등급·소진율 색상 (근거: SPEC_META_PERFORMANCE, SPEC_GADS_PERFORMANCE).
- **⛔ 금지**: "ROAS/전환/매출 상승 보장"(조회·관리 도구). ✅ 지출순 정렬·검색어 목록은 정상 조회.

## B15. AI 마케팅 챗봇
- **한 줄**: 말로 물어보면 성과 수치·기능 설명·광고 조작까지 처리하는 대화형 마케팅 비서.
- **프로세스**: 자연어 질문 → 4코스 자동 판별(데이터 조회·지식 설명·광고 실행·외부 안내) → 조회는 카드로, 설명은 정리된 지식으로, 실행은 광고관리와 연결(**위저드에서 확인해야 실행**), 답 못 하는 건 외부 안내.
- **핵심 사실**: 4코스 라우팅 / 조회 최대 3개월 / 트렌드 랭킹(29CM·에이블리) / 기간 비교(지난주·지난달·작년동월) / 성과 세트(월매출 YoY·CTR·ROAS·28일 평균 대비) / 광고 제어는 **위저드 확인 후 실행**(자동집행 아님), 범위=예산·ON/OFF·키워드 추가·저성과 제외 (근거: chatbot-pipeline §ACTION).
- **⚠️ B15 근거 주의**: 근거 파일 `chatbot-pipeline.md`는 2026-06-28 이후 **구형**(원본 상단 명시). 4코스·외부안내 종결 골격만 유효, 세부 수치·안전게이트·톤 철학은 대시보드 세션 현행 정본(`docs/ctx/chatbot/`, 아직 미복사)에서 재확인 필요. "±50%·본인 계정" 등 레포 내 근거 없는 항목은 제거했다.
