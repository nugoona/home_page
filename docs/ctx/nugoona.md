## Design Rules

### Layout
- 컨테이너: `OuterContainer` (max-w-1200px) → `Section` (noBorder/alt/dark/crossMarks)
- 텍스트 영역: max-w-[720px] mx-auto
- 섹션 패딩: Desktop px-12 py-16 / Mobile px-6 py-12
- 그리드: Desktop 3-col → Mobile 1-col (max-md:grid-cols-1)
- 반응형 분기: max-md: (900px), max-sm: (600px)

### Typography
- Hero: `text-[clamp(26px,5vw,56px)] font-bold`
- Section: `text-[clamp(28px,4vw,40px)] font-semibold tracking-[-0.02em] leading-[1.15]`
- Body: `text-[15px] font-light leading-[1.65]`
- EN 악센트: `text-[13px] font-semibold tracking-[0.1em] uppercase` + font-en

### Animation
- 기본: `<FadeUp delay={0.1}>` (600-800ms, cubic-bezier)
- 숫자: `<CounterUp target={N} />`
- ease: `[0.16, 1, 0.3, 1]`

### Dark Section
- 배경: `linear-gradient(180deg, #0a0a0a, #151515)`
- 텍스트: `text-white`, `text-white/80`
- CTA: `bg-white text-text-primary`

### 금지 사항
1. border-radius 추가 금지 (전역 리셋, 예외: .rounded-pill, .rounded-dot)
2. hex 하드코딩 금지 (Tailwind 토큰 클래스 사용)
3. inline style={{ color/background }} 금지
4. 1200px 초과 폭 금지
5. clamp() 없는 헤딩 금지
6. 콘텐츠 직접 작성 금지 (lib/content/*.ts에 분리)
