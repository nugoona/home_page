## Design Rules

### Layout
- CSS Modules (*.module.css) — Tailwind 사용 금지
- 섹션: `.section` + `.container` (max-width: var(--max-content))
- 패딩: var(--section-py) 120px → 80px@1200px → 60px@768px
- 헤더 높이: var(--header-height) 80px → 64px@768px
- 모바일 하단: MobileBookingBar 56px 고정

### Typography
- Heading: var(--font-heading) Arita Buri, weight 300-400
- Body: var(--font-body) Gowun Batang, weight 400, line-height 1.6+
- Display: var(--font-display) Cormorant Garamond
- Label: var(--font-ui) Pretendard, 13px, letter-spacing 0.12em
- Scale: clamp() 반응형 (--text-hero ~ --text-xs)

### Animation
- GSAP + ScrollTrigger (Framer Motion 아님)
- ScrollReveal: IntersectionObserver 기반 fade-up (threshold 0.15)
- 스태거: .reveal-delay-1 ~ .reveal-delay-4
- Desktop pinning: ScrollTrigger.pin (시네마틱 히어로)
- MagneticButton: 마우스 추적 탄성 효과

### Buttons
- `.btn--primary`: gold bg, white text
- `.btn--secondary`: gray border, transparent
- `.btn--ghost`: gold border, transparent
- border-radius: 2px (최소)

### 금지 사항
1. Tailwind 사용 금지 (CSS Modules 전용)
2. hex 하드코딩 금지 (var(--gold) 등 CSS 변수 사용)
3. Framer Motion 사용 금지 (GSAP 사용)
4. sans-serif를 heading에 사용 금지 (serif: Arita Buri)
5. 둥근 모서리 남용 금지 (max 2px)
6. header-height 무시 금지 (body padding-top 필수)
