## 0.5 카피 글쓰기 규칙 (Voice & Copy Rules) — 사장님 확정 2026-07-07 · 카피 작성 시 최우선

> 모든 랜딩 카피(/content·/ads·홈·/start)는 이 규칙을 통과해야 한다. 상세 근거·리서치 원자료 = `docs/랜딩-아이디어로그.md` 카피 원칙 블록.

**① 톤 — 품위·열망 공감 (사장님 반복 지적 지점)**
- ⛔ **적대적·자극적·"싼티"·공포·대행 저격 금지.** ("매달 몇십만 원 왜 안 보일까요"·"저품질로 처박히고" 류 = 반려)
- **열망 공감형으로 연다** — 고객이 이미 원하는 상태를 대변: *"누구나 검색 결과에 내 스토어가 바로 보이길 원합니다."* ("누구나"=브랜드명 중의로 강력)
- **"가게" → "스토어"** 표기(사장님 선호). ⛔"소상공인"·영세·마이너어 금지(격 있게).
- 담백한 사실 대비는 OK(광고=멈추면 소멸 vs 콘텐츠=쌓임). 비방·인용 저격(보장·1등 인용 반전)은 X.

**② 구조 — 다이렉트 마케팅 (기능부터 설명 금지)**
- ⭐⭐ **내용이 먼저, 표현은 그다음.** 카피를 쓰기 전에 **"이 섹션이 증명할 단 하나의 메시지(근거 있는 진짜 내용)"를 먼저 정한다.** 틀·형식("누구나 ~하고 싶어 합니다" 같은)에 내용을 억지로 끼워 넣지 마라 — 그 열망·주장에 **근거가 있는지** 먼저 따진다. (반례: /ads 히어로에 "누구나 직접 운영하고 싶어 한다"를 근거 없이 /content 형식만 복사 = 반려. 표현 기술을 내용보다 앞세우는 것이 가장 흔한 실패.)
- 순서: ①고객 세계 진입(열망 공감, 고통 자극 아님) → ②상식 전환 → ③진짜 원인 → ④**그 후에야** 서비스.
- 첫 문장 = 멈춰 읽게. **목적어·주어 명확**(무생물 의인화·목적어 생략 금지 = "매달 쓰고도"→뭘? / "검색이 기억한다"→주체? = 반려). 형용사 tell 대신 명사·숫자 show. 한 줄 15자 안팎.
- **CTA·행동 유도 문구는 "뭘 하라는지" 명확히.** "오늘, 스토어 이름 하나부터"(X — 행동 없음) → "오늘, 스토어 이름만 한 번 입력해 보세요"(O — 구체 행동).
- **개수·목록을 카피에 박지 마라.** "여섯 곳"(X — 매체 추가 시 홈페이지 수정 부채) → "채널마다/모든 채널에"(O). 단위는 "곳" 대신 **채널·매체**(한국어에서 매체를 "곳"으로 세지 않음).
- **자기도 뜻을 정확히 설명 못 하는 문장은 쓰지 마라.** 모든 카피는 "이게 정확히 무슨 뜻이고, 왜 참인지"를 한마디로 말할 수 있어야 한다. ("블로그만이 아니라 지도에서도 찾게" = 주어·대상이 붕 뜬 반려 사례.)
- **어정쩡한 우려 제기(반문) 금지.** 우려·통념을 카피에 꺼내려면 **뒤에 그것을 확실히 뒤집는 강력한 반박**이 반드시 따라와야 한다(약한 반박은 오히려 그 불안을 각인시킴). 반박이 약할 것 같으면 우려를 꺼내지 말고 **장점을 정면으로 직격**하라. ("사람이 관리해야 안심되시죠?"처럼 반박 약한 반문 = 반려 → "언제 물어도, 몇 번을 물어도 답합니다"처럼 강점 직격.)
- 검증 문장: **"이 문장을 경쟁사가 똑같이 쓸 수 있나?"** → 그렇다면 버즈워드다.
- **주어와 매칭되는 강한 동사를 써라.** "~해집니다 / ~집니다"(형용사+지다 = 피동·상태변화)는 힘이 약하다 → 능동·구체 행위 동사(덜다·걷어내다·줄이다·끝내다·되찾다·빼다 등)로. ("광고가 편해집니다" ✗ = 약한 피동 / "광고 부담을 덜어냅니다" ✓ = 강한 능동.)

**③ 금지 표현**
- 과장 약속: 1등·보장·최저가·최고·100%.
- 버즈워드: 혁신·최적화·솔루션·스마트·원스톱·쉽습니다·편리합니다·디지털 전환.
- "AI·자동·효율" 남발(꼭 필요한 1회만, 나열 금지).
- **저렴·저속한 구어 금지**: "굴리다/굴린다"(광고를 굴리다 등) 같은 값싸 보이는 표현 → 품위 있는 동사로(직접 하다·운영하다).

**④ 정직 가드레일 (리서치 근거)**
- "발행한 글이 검색 자산으로 남는다" = **조건부 사실.** 반드시 **"꾸준히/제대로 쌓은"** 조건어를 붙인다 — "발행만 하면 자동"은 거짓(웹 콘텐츠 96.55%는 검색 유입 0, 자산이 되는 건 상위 노출 + 주기 갱신한 소수 글). → **우리 제품 정당성** = 그 꾸준함·갱신을 스토어 사장님 대신 충족한다.
- 근거: 네이버 C-Rank(출처 신뢰도·한 주제 꾸준함)·D.I.A(경험·독창)=네이버 **공식** / 임대 vs 소유(Joe Pulizzi) / 소상공인 현실(대행 실망·광고 종속). 완성 전제·현재형.

**⑤ 카피 사고 방법론 (문구보다 먼저 — "어떻게 도출하는가". GPT 대비 학습 2026-07-08, 사장님 지시)**
> ⛔ 실패 패턴: 표현 기술만 돌리고 이 사고 단계를 건너뛰면 매번 반려된다. 문구를 쓰기 전에 아래를 통과하라.
- **브랜드 슬로건 = 기능도 니즈도 아니라 '상태(state)'를 말한다.** 근원 니즈가 *충족된 상태*를 보여줘라. 니즈를 직접 말하지 마라. (예: 니즈="확신" → "확신을 드립니다"[직접·약함] ✗ → "내 광고를 내가 압니다"[확신이 생긴 상태] ✓ — 독자가 스스로 확신을 느낀다.)
- **히어로는 고객의 욕망에서 시작하라. 경쟁 구도에서 시작하지 마라.** ("대행 없이…"[경쟁구도] 보다 "내 광고를 내가 안다"[고객 욕망]가 강하다.)
- **브랜드 히어로 ≠ 캠페인 카피.** 히어로는 10년 써도 질리지 않고 · 사용자가 주인공 · 부정 감정/공격/스토리로 시작하지 않는다. (부정·자극·반전 스토리는 캠페인용 — 브랜드 히어로엔 과하다.)
- **후보는 장점만 보지 말고 약점을 해부하라.** 시작 단어·어휘·톤을 미시적으로. "이제/드디어" 같은 시간부사는 힘이 약하니 뺀다.
- **넓게 펼치고 좁혀라.** 축(상태·확신·주도권·감성)별로 20개+ 펼친 뒤 → TOP5 → 최종 1.
- **2단 구조로 실행.** 히어로=상태(감성)로 시작 → 서브카피 첫 문장에서 근원 니즈를 명시적으로 잇고 → 나머지 서브에 기능을 증거로. ("브랜드는 감성으로 시작, 제품은 기능으로 증명.")
- ⭐ **히어로는 '카테고리·시대 선언'으로 궁금증을 열 수 있다 (사장님 확정 2026-07-08, /ads 채택 방식).** 개별 기능·상태를 콕 집는 대신 제품이 속한 **새 카테고리를 선언**("AI 시대의 온라인 광고")해 **호기심(curiosity gap)을 유발** → "그게 뭔데?" 하고 읽게 만들고 → 하위 섹션(대행 없이 직접·수수료 없음·챗봇·통합)이 그 **답으로 설득**한다. **히어로=질문(궁금증의 문) / 하위=답.** (벤치마크: Triple Whale "The AI OS for modern ecommerce". 이때 "AI 시대"의 AI는 시대 선언이라 ③ 'AI 남발 금지'의 예외 — 금지 대상은 기능 설명에서 습관적으로 AI를 붙이는 것.)
