# 앱 화면 촬영본 — 홈페이지 콘텐츠 페이지 "이 밖에도 필요한 기능을 담았습니다" 구간용

- 찍은 날: 2026-10-09 · 찍은 곳: 업로드 앱 개발 서버(localhost:3000) · 폰 폭 390(2배 해상도 → 파일은 780px 폭)
- 시험 가게 = **온기 한식당**(가상 이름). 업로드 앱의 시험 업체 계정으로 찍고 화면에 보이는 가게 이름만 가상 이름으로 바꿨습니다. 실제 손님·실제 가게 정보는 없습니다.
- 음식 사진 4장(김치찌개·제육볶음·반찬·된장찌개)은 AI 가 만든 시험 사진입니다. 홈페이지가 다른 사진을 쓰고 싶으면 알려 주십시오. 사진만 바꿔서 다시 찍어 드릴 수 있습니다.
- 각 장은 앱의 **실제 화면 코드**로 그린 것입니다. 데이터만 시험용입니다(상세는 맨 아래 "어디까지 실제인가").
- 긴 화면(`02.png` 등 세로가 긴 파일)은 한 화면에 다 들어가지 않는 목록을 끝까지 보이게 화면 높이를 늘려 찍은 것입니다. 홈페이지에서 필요한 부분만 잘라 쓰면 됩니다.
- 모든 화면 맨 위의 파란 **[문의]** 띠는 앱 어느 화면에나 떠 있는 "앱 안 문의함" 입구입니다(지도 184). 사진에서 지우지 않았습니다.
- 🔴 **사장님 결정(2026-10-09): 앱 캡처 PNG 를 홈페이지에 그대로 넣지 않는다.** 앱 세부 디자인이 아직 안 다듬어졌다(구분선 과다 · 진행 막대 · 어색한 문구). 홈페이지는 이 문서의 **문구·흐름·상태 이름**만 가져가 지금 네일 질문 장면처럼 홈페이지 문법으로 **다시 그린다.** PNG 는 구조 참고용. 어색한 문구는 뜻이 같으면 자연스럽게 다듬어도 된다(기능 약속만 바꾸지 말 것).

## 1-question — 사진을 보고 필요한 것만 물어보기 (지도 24 · 20 · 357)
