# 접수 대장 (Intake) — 대표/발주처에 요청할 것 & 받은 것

> 한 번에 다 못 받는다(이미지·원고는 조각으로 온다). 이건 '게이트'가 아니라 **누적 대장**이다.
> 받을 때마다 상태를 갱신하고, "아직 안 받은 것"을 항상 위에 표시해 매 단계에서 리마인드.
> 이 파일을 복사해 `00_intake.md`로 저장해 쓸 것.

## ⛔ 아직 안 받은 것 (여기부터 채운다)
- [ ] (예) 04장에 넣을 실적 로고 원본
- [ ] (예) 대표 프로필 사진 고해상

---

## A. 발주처에서 받아야 (입찰 규격 — 미달 시 실격)
- [ ] 공고문 / 제안요청서(RFP) 원문
- [ ] **평가 배점표** (어디에 점수가 걸렸는지 = 어필 우선순위)
- [ ] 필수 목차 / 반드시 포함할 항목
- [ ] **제출 규격**: 비율(16:9?), 장수 제한, 파일 용량 한도, 파일 형식(PPTX/PDF/인쇄본), 파일명 규칙
- [ ] 제출 기한
- [ ] 발주처 CI/브랜드 가이드(로고, 색, 금지사항) — 있으면

## B. 우리(대표)에게서 받아야
- [ ] **대표 원고** (슬라이드에 들어갈 문구 원문 — 지어내기 금지의 기준). `원고.md`로 고정
- [ ] 장별 강조점 / "이 장에서 꼭 각인시킬 것"
- [ ] 이미지 원본 (현장/시설/인물/실습 등) — 어느 폴더인지 경로까지
- [ ] 실적 데이터 (매출·리뷰·평점·거래처 등 숫자와 출처)
- [ ] 조직/인력 정보 (경력, 자격, 구성)
- [ ] 재무 자료 (필요 시)
