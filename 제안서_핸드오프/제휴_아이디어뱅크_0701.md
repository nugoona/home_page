# 하나금융 제휴 아이디어 초안 (아우름 대표 검토용) — 2026-07-01

> 초안. 실무 검토 → 수정 → 아우름 대표 컨펌 순서. 전부 예시(가격·조건 미확정).
> 확정되면 슬라이드(운영방안 등)에 '제휴' 소절로 반영. 슬라이드엔 "있다"만, 상세는 발표로.

---

## 큰 그림 — 왜 이게 강력한가 (영업이 아니라 '혜택')

상주형 경쟁사는 "하나금융 건물 안에서, 정해진 근무시간에만" 서비스가 됩니다. 우리는 **부평역 샵이 하나금융과 30분 거리**라, 상주 없이도 **상주에 준하는 접근성**을 '제휴'로 만들 수 있습니다. 이게 우리 약점(상주 경험 없음)을 정면으로 덮고, 아무도 못 내는 카드입니다.

핵심은 **영업이 아니라 혜택**입니다. 우리 샵은 **별점 4.96(리뷰 600개 이상)**으로 이미 검증됐고, 밖에서 **기본 건식만 6만 원**인 케어를 하나금융 직원에겐 **2만 원**에 제공합니다. 즉 "**퀄리티는 보장, 가격은 최저**"인 곳과 제휴하는 것 자체가 직원 복지입니다. 그 퀄리티의 근거는 리뷰만이 아니라 — **교육 시스템, 자격증, 그리고 대표가 직장인이 어디가 왜 아픈지·뭘 풀어야 만족하는지 정확히 아는 실력(지피지기)**입니다. 단순 타이·중국식이 아니라 **도수치료 이상**의 케어입니다.

## 아이디어 (다다익선 — 전부 예시)

### 접근성·시간 확장 = 상주 대체
1. **근무 외 방문 케어 (핵심)** — 근무 4시간 안에 예약을 못 잡은 직원도, 부평 샵 운영시간 안에 오면 같은 조건으로 받게 함. "정해진 시간에 못 와도 샵으로 오면 된다." → *상주 없이 상주급. 이용률·만족도 상승.*
2. **야간·주말 확장** — 근무일 외 저녁·주말에도 하나금융 직원 인정 예약. → *낮에 못 쓰는 직원까지 커버 = 실질 이용률 극대화.*
3. **직원 전용 우선 예약 라인** — 일반 손님과 별도 우선 슬롯. → *대기 없는 '특별대우' 체감.*

### 웰니스 범위 확장 = 직무 밖 서비스
4. **피부미용·바디케어 제휴가** — 근무 중엔 못 받는 샵 정규 서비스를 직원 전용가로. → *웰니스가 회사 안에서 끝나지 않고 밖으로 이어짐.*
5. **통합 웰니스 패키지** — 근골격+피부+체형 묶음 코스. → *한 곳에서 다 되는 원스톱, 상주형은 불가능.*
6. **시즌·이벤트 케어** — 환절기·연말·건강검진 시즌 맞춤 프로그램. → *정기 접점 = 지속성.*

### 관계·복지 확장
7. **가족·동반 1인 확대** — 직원 본인 외 가족/동반까지 제휴 조건. → *복지 체감이 가족까지, 상주 업체는 못 함.*
8. **인사제도 연계 리워드** — 신규 입사·장기근속·우수직원 웰컴/보상 케어(하나금융 HR 연계). → *제도화된 복지 = 심사 신뢰.*
9. **팀 단위 단체 케어** — 부서 회식 대신 팀 웰니스 이벤트. → *조직문화 기여 = 기대효과.*

### 전문성·건강관리 = 실력 증명·도수 대체
10. **대표 진단 기반 정기 근골격 관리** — 대표가 직접 통증 지점 진단 후 정기 트랙. → *도수치료 대체 포지션, 실력 증명.*
11. **직장인 특화 사전 문진·맞춤 케어** — 어디 아픈지 데이터로 받고 맞춤. → *단순 마사지와 격이 다름.*
12. **사후관리·홈케어 가이드** — 케어 후 자가관리 안내(월간 리포트 연계). → *9번 데이터·KPI와 시너지.*

### 데이터·제도화 = 심사 신뢰
13. **제휴 이용 리포트 통합** — 이용률·만족도를 월간 운영 리포트에 가시화. → *운영 투명성 = 기대효과 근거.*
14. **자세·건강 세미나(예방)** — 샵 교육 노하우로 직장인 자세 교육. → *치료를 넘어 예방까지 = 웰니스 완결성.*

## 사용 안내
- 초안입니다. 대표가 "이건 좋다 / 이건 빼자 / 이렇게 바꾸자" 주시면 반영해 다시 다듬은 뒤 최종 컨펌.
- 슬라이드엔 이 상세를 다 넣지 않음("있다"만, 발표로 풀이). 확정 시 운영방안 등에 소절로 반영.
