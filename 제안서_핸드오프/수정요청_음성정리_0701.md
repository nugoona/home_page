# 하나금융 제안서 — 확정 내용가이드 (2026-07-01, v2 확정)

## ★ 우선순위 (북극성)
1. **대표 음성 녹음 = 영순위(북극성).** 무엇이든 이게 최우선.
2. **대표 카톡 내용가이드** (음성과 함께 대표의 뜻).
3. **공고** = 그 아래. → **대표 말이 공고를 이긴다.** "할 수 있다/없다" 같은 표현도 공고가 금지해도 **대표 지시가 우선**. (공고 기준으로 대표를 교정하지 말 것)

## ★ 삭제 규칙
- 표의 "삭제 가능"(4·6·7·8번)은 **지금 삭제가 아님.** **일단 전부 유지.**
- **페이지를 새로 만들어 15장을 넘길 때만** 그때 삭제해 분량을 맞춘다.

## ★ 일정

## 0. 대전제
- **차별점 = "부평역 샵 운영 + 하나금융 30분 내 근접"** (공고의 운영능력 25점 "기타 차별화 방안" 항목에 대응 = 배점 항목).
- 프레임: 샵 **홍보 아님** → **"몇 년 운영한 샵 노하우를 하나금융에 그대로 이식"**.
- 약점 = **상주(상시 파견) 운영 경험 없음** → 첨부/레퍼런스로만 보완, 슬라이드 노출 최소.

## 1. 전역 수정
1. **용어 전면 교체**: "안마사·마사지" 금지 → **웰니스 케어 / 근골격 케어** (카톡 확정값).
2. **3대 평가영역 제목 크게·명확히**: 사업능력·운영능력·인력계획 = 공고 배점 3항목(10/25/25)과 동일 → 심사위원 채점 편하게 큼직하게.
3. **모호표현 처리**: 기본은 "이미 시행 중" 단정형. **단, 표현은 대표 지시 우선**(공고의 모호어 금지보다 대표 말이 위).
4. "패스트5(FastFive)" = 공유오피스 실적처 → **4번 상세 삭제 대상과 동일 건**(별도 용어확인 불필요).

## 3. 추가 페이지 (신규 — 공고 배점 대응)
> ⚠️ 신규장은 **실무자가 구성안을 먼저 잡아 대표 컨펌 후** 제작. 지금 바로 슬라이드부터 만들지 않는다.

### A. 차별점 강조 (신규 1~2장) — 최우선 `운영능력·기타 차별화 방안`
- 근접성: **부평역 샵 ↔ 하나금융 30분 내** → 즉시 대응·즉시 인력 보충. **상주 안 해도 상주급.**
- 노하우 이식·안정 운영·희소성("샵 운영하며 이 일 하는 업체 거의 없다").
- 실력 근거: **별점 4.96 (리뷰 600개+ 평균, 소수 평균 아님)**, 교육 시스템, 자격증(대표 자격증 포함), 기업 실적, 세탁수거.

### B. 제휴 (차별점 장 안에 '제휴' 소절로 통합) `운영능력·직원만족` — **무조건 포함**
- **영업/할인 이벤트 아님 = 전략적 제휴.** 상주 업체는 회사 안에서만 → 우리는 **상주 외 제휴**로 확장.
- **왜 혜택인가**: ①**퀄리티 보장 + 가격 낮음** — 샵 기본 건식 6만원선을 하나금융 직원은 **2만원**에. ②퀄리티 근거 = 대표가 직장인 어디 아프고 뭘 풀어야 만족하는지 정확히 앎(지피지기) → 필요한 케어, **도수치료 이상**, 고객관리 가능(단순 타이/중국 마사지 아님).
- **근접성 제휴 예시**(전부 예시, **가격 확정 금지**, 대표 컨펌 후 별도 확정): 하나금융 직원 인정 → 근무 4시간 외에도 **샵 운영시간 내 방문 시 동일 조건** / 피부미용 등 샵 서비스 제휴가·전용 프로그램 / (필요 시) 가족·동반 확대.
- **표기 방식**: 상세·수치는 슬라이드에 적지 말고 **"있다"만** → 대표가 발표로 풀이.

### C. 직장인 전문 소구 `직원만족`
- "직장인에게 인정받은 샵" — 6만원값을 2만원에, 리뷰/댓글 차용, 평점 4.96.

### D. 상주 경험 1건 (약점 보완) `인력계획`
- **첨부/레퍼런스 파일에만**, 업체명 비공개(코로나 이전). 슬라이드 노출 없음.

### E. 샵 사진 (선택)
- 잘 나온 컷 모퉁이 하나(홍보 아닌 운영 근거 톤).

- **제휴 서비스 구체안·가격** = 대표 컨펌 후 별도 확정(현재 미정, 예시만).
