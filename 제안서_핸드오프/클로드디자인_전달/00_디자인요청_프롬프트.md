## ■ 프롬프트 (복사용)

당신은 시니어 프로덕트 디자이너입니다. 아래는 **하나금융그룹 웰니스케어 위탁운영 입찰 제안서**의 슬라이드 한 장으로, 이미 완성된 HTML입니다. 이걸 **처음부터 다시 만들지 말고, "다듬어(polish)"** 주세요.

**규격**: 16:9 가로 · 1920×1080 · 발표용 PPT 슬라이드.
**브랜드**: 아우름웰니스(기업 웰니스 "운영" 회사). 톤은 **Vercel처럼 깔끔하고 미니멀**하되, 지금은 "AI가 자동 생성한 티"가 나서 **더 고급스럽고 세련되게 정제**가 필요합니다.

### 다듬을 것 — 이 6가지만
1. **공간·여백**: 표·카드 "안"에 여백이 뜨는 곳을 적정 밀도로 좁혀 주세요. (내용을 억지로 늘려 빈 칸이 생긴 부분을 정리)
2. **표 너비**: 너무 넓게 퍼져 여백이 생긴 표/칸은 폭을 조여서 밀도 있게.
3. **타이포**: 글자 크기·자간·굵기의 위계를 정제. (빅넘버 / 제목 / 본문 / 라벨의 단계가 또렷하게, 자간은 한글 -0.02em 안팎)
4. **색감**: 톤앤매너에 맞게 미세 조정. 그린(#00857A)은 **핵심 1~2곳만**(헤드라인 키워드·체크·라벨), 숫자와 본문은 **검정(#171717)**. 옅은 파스텔 면(연그린 배경 등)은 쓰지 말 것.
5. **데코·패턴**: 코너 브래킷·격자·헤어라인 같은 요소를 **적절히 어우러지게** 배치해 고급감을 주세요. (과하지 않게, 여백 있는 곳에만)
6. **디테일**: 아이콘·구분선·간격의 미세 정리로 완성도.

### 절대 하지 말 것
- **레이아웃 구조 변경 금지** — 좌우 배치·섹션 순서·전체 골격은 그대로.
- **텍스트·숫자·문구 변경 금지** — 내용은 확정됐습니다. 오타 수정 외 임의 변경 X.
- **이미지 교체·삭제 금지** — 첨부 이미지 그대로 사용.
- **대시(— 또는 –) 사용 금지** → 가운뎃점(·)이나 문장 연결로.
- **텍스트 화살표(→ ↓) 금지** → 아이콘(SVG)으로.
- **숫자와 단위 붙이지 말 것** — "16명" 등에서 숫자·단위 사이 살짝 간격.

### 유지할 디자인 시스템
- 폰트: **Pretendard**(한글) + **Inter Tight**(영문·숫자)
- 색: 딥그린 `#00857A` / 잉크 `#171717` / 본문 `#3d3d3d` / 헤어라인 `#eaeaea` / 다크 배경 `#06201d`(표지·클로징)
- 자세한 토큰은 `00_디자인시스템_토큰.md` 참조.

**작업 결과**는 같은 1920×1080 HTML로, 13장 전체가 하나의 통일된 톤이 되도록 해주세요.

## ■ 이 제안서의 큰 메시지 (전 장 공통 톤)
