# Claude Design 전달 방법 (사장님용 사용 안내)

## 이 폴더 구성
```
클로드디자인_전달/
├─ 00_디자인요청_프롬프트.md   ← Claude Design에 붙여넣을 프롬프트 (핵심)
├─ 00_디자인시스템_토큰.md     ← 색·폰트·간격 기준 (일관성)
├─ 00_전달방법_안내.md         ← 이 문서
└─ 슬라이드/
   ├─ 01_표지/         slide.html + imgs/ + brief.md
   ├─ 02_운영방안/     slide.html + imgs/ + brief.md
   ├─ ...
   └─ 13_클로징/
```
각 장 폴더 안:
- `slide.html` — 그 장의 완성 HTML (이걸 다듬는 것)
- `imgs/` — 그 장이 쓰는 이미지 (04는 하위폴더 logos/·portfolio/ 포함)
- `brief.md` — 그 장의 핵심 메시지·다듬을 포인트

## 방법 A) 한 장씩 다듬기 (권장 — 품질 안정적)
1. **claude.ai/design** 접속 → 새 디자인
2. 첫 메시지에 붙여넣기:
   - `00_디자인요청_프롬프트.md`의 「■ 프롬프트」 블록 전체
   - + 그 장 `brief.md` 내용
3. 첨부:
   - 그 장 `slide.html` (코드 그대로 붙이거나 파일 첨부)
   - 그 장 `imgs/` 이미지들
   - (참고용) 현재 렌더 스크린샷이 있으면 함께 — "이 상태를 다듬어달라"
4. 결과가 나오면 **Code Handoff**(코드 내보내기)로 HTML 받기
5. 받은 HTML을 원래 파일명(`v3_slide01.html`)으로 저장 → 브라우저로 확인

→ 01번부터 13번까지 같은 프롬프트로 반복. **13장을 같은 세션에서 연달아** 하면 톤이 통일됩니다.

## 방법 B) 한 번에 여러 장 (빠르지만 편차 가능)
- 프롬프트 + 여러 장 HTML/이미지를 한 대화에 넣고 "이 톤으로 전부 통일해서 다듬어달라".
- 장수가 많아 품질 편차가 생길 수 있어, 표지·클로징 같은 중요 장은 방법 A로 따로.

## 꼭 챙길 것
- **레이아웃·텍스트·숫자는 그대로** (다듬기만). 결과에서 문구가 바뀌었으면 되돌리기.
- **대시(—)·텍스트 화살표(→) 금지** — 결과에 있으면 고쳐달라고.
- **1920×1080 고정** — PPT 변환을 위해 크기 유지.
- 결과 HTML은 이 레포 `제안서_핸드오프/slides/`에 최종본으로 덮어쓰면 백업됩니다.

## 최종 산출 (PPT 변환)
13장 HTML이 다 다듬어지면 → 각 장 1920×1080 스크린샷(PNG) → PowerPoint에 넣어 .pptx로 (또는 HTML→PDF→PPT). 발표용 10부 + USB 제출.
