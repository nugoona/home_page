# 디자인 시스템 토큰 (13장 공통 — 이 값을 유지하며 다듬기)

## 색 (Color)
| 용도 | 값 |
|---|---|
| 브랜드 그린 (강조 핵심) | `#00857A` |
| 그린 딥 (진한 강조) | `#006a61` |
| 그린 라이트 (다크 배경용 민트) | `#00b39e` |
| 잉크 (제목·숫자) | `#171717` |
| 본문 | `#3d3d3d` |
| 약한 본문 | `#4f4f4f` |
| 캡션·라벨 | `#5f6670` |
| 헤어라인·구분선 | `#eaeaea` |
| 다크 배경 (표지·클로징) | `#06201d` / 그라데이션 `#0e302b → #07201b` |

**원칙**: 밝은 슬라이드(2~12)는 흰 배경 + 그린 절제(핵심 1~2곳). 숫자·본문은 검정. 표지·클로징만 다크.

## 폰트 (Typography)
- 한글: **Pretendard** (`word-break:keep-all`)
- 영문·숫자: **Inter Tight** (라벨·빅넘버·페이지번호)
- 자간: 큰 타이포 `-0.035em`, 본문 `-0.01em`, 영문 라벨 `+0.12~0.16em`(대문자)

### 크기 위계 (밝은 슬라이드 기준)
| 요소 | 크기 / 굵기 |
|---|---|
| 헤드라인(big) | 46~54px / 800 |
| 리드(lead, 윗줄) | 22~25px / 500 |
| 빅넘버 | 29~42px / 600 (자간 -0.04em, 얇고 크게) |
| 섹션 제목 | 15~19px / 600~700 |
| 본문 | 13.5~15px / 400 |
| 라벨(EN) | 11~12px / 700 (대문자·자간 넓게) |

## 레이아웃
- 캔버스: 1920×1080, 패딩 `74px 96px 58px`
- 킥커(좌상단): 번호 박스 30×30 + 제목 + EN 라벨
- 페이지번호(우상단): `NN / 13`
- 헤드라인 → 본문 → (하단 결론 다크 띠) 구조

## 공통 컴포넌트
- **킥커**: `<번호> <한글제목> <EN라벨(그린)>`
- **뱃지**(우상단): 테두리 박스 + 아이콘 + 2줄 텍스트
- **다크 결론 띠**: `linear-gradient(150deg,#0e302b,#0a2521)` + 흰 텍스트 (장당 최대 1개)
- **데코**: 코너 브래킷(딥그린), 격자(opacity .035), 십자 헤어라인 — 여백 있는 곳에만

## 아이콘
- **Lucide** (`https://unpkg.com/lucide@latest`) — 모든 도형·화살표는 이걸로. 텍스트 화살표 금지.

## 금지
- 대시(— –) → 가운뎃점(·)
- 옅은 파스텔 면(연그린·연회색 배경 박스)
- 그린 남발(빅넘버·표 숫자 전부 그린 X)
- 카드/표 안에 뜨는 여백 (flex로 억지로 늘리지 말 것)
